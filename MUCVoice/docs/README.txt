MUCVOICE v0.5beta — MSX-DOS2용 MUCOMSX SCREEN 2 음색 편집기
2026-10-15
=============================================

상세 사용설명서: 한국어 README.TXT / English MANUALEN.MD / 日本語 MANUALJA.MD
MANUALEN.MD와 MANUALJA.MD는 PC에서 읽는 UTF-8 문서입니다.

MUCVOICE.COM은 MSX에서 직접 실행하는 Z80 프로그램입니다.
YM2608 FM 음색과 SCC/SCC+ 공통 32샘플 파형을 한 프로그램에서 편집하고 DAT로 저장합니다.
웹 브라우저나 PC용 Python은 실행에 필요하지 않습니다.

기본 화면은 SCREEN 2(256×192) 그래픽 편집기입니다. 3×5 폰트, 4픽셀 글자 간격의 64열과 검정·흰색·시안·파란색 계열을
사용합니다. 큰 폰트를 축소한 것이 아니라 원래 작은 글리프를 그립니다. 화살표로 항목을
선택하고 그 자리에서 숫자를 입력합니다. Enter로 진입할 필요가 없습니다.
숫자는 Enter로 적용하거나 Tab으로 적용 후 다음 칸으로 이동합니다.
F2/E/Enter는 기존 값을 전체 선택해 편집합니다. Esc는 편집을 취소하며
메인 화면에서 종료하지 않습니다. 종료는 Q/Ctrl-Q입니다.
파일명·확인 답변은 Enter로 확정합니다.
MUCVOICE /TEXT로 실행하면 기존 숫자 입력형 콘솔 인터페이스를 사용합니다.

빠른 조작
---------
P: 현재 뱅크의 기본 프리셋, O/Ctrl-O: DAT 파일 브라우저.
Space: A4 미리 듣기, C D E F G A B: 음표 미리 듣기, Shift: 위 옥타브.
K: 전체 건반 모드, S/Ctrl-S: DAT 저장, U/Ctrl-Z: Undo, Q/Ctrl-Q: 종료.
선택만으로 뱅크를 바꾸지는 않습니다. P의 Enter는 한 슬롯 적용,
O의 Enter는 DAT 뱅크 전체 읽기이므로 먼저 개인 뱅크를 보관하세요.

FM/SCC 프리셋 선택 화면과 DAT 파일 브라우저에서 C D E F G A B로
선택한 음색의 도레미파솔라시(C4..B4)를 적용 전에 연주합니다. 문자 대소문자와
Caps Lock은 같은 음이며, 실제 Shift를 함께 누르면 한 옥타브 위(C5..B5)입니다.
높은 도는 Shift+C입니다. 문자 건반은 누르는 동안 발음하고 놓으면 정지합니다.
한 번에 한 음이며 새 건반을 누르면 그 음으로 바뀝니다. 선택 이동/취소/적용 시
정지하고, 길게 누른 음도 180틱 후 안전 정지합니다. 화면에 현재 음을 표시합니다.
이 조작은 P/O 선택 화면 전용으로, 메인 편집 단축키와 K 건반 배열은 그대로입니다.
음 키를 누른 채 Enter/Esc를 누르면 먼저 음을 끄고, 해당 음 키를 놓은 뒤
적용/로드 확인/복귀를 진행합니다. 남은 반복 입력이 편집 단축키로 넘어가지 않습니다.
폴더·잘못된 DAT 등 발음할 수 없는 항목에서도 이 처리를 적용합니다.
키 해제를 기다릴 때 PLAY 표시도 즉시 지워 실제 정지 상태를 보여 줍니다.

기존 Space 미리듣기도 유지합니다. FM/SCC 프리셋과 DAT 파일 브라우저에서
미리듣기를 지원합니다. 선택한 음색의 A4음을 재생하며 다시 Space, 다른 키로
이동/적용/취소, 또는 180틱 경과 시 정지합니다(60Hz 약 3초, 50Hz 약 3.6초).
Space를 길게 눌러도 반복해서 켜졌다 꺼지지 않습니다. 우측 상단 A4 PLAY가
발음 표시입니다. FM은 MAKOTO, SCC/SCC+는 자동 탐색한 카트리지 CH1을 사용합니다.
하드웨어가 없거나 응답하지 않으면 NO CHIP으로 알리고 편집은 계속합니다.
현재 음색 슬롯, 미저장 상태, Undo, 파일은 바꾸지 않습니다. 적용은 여전히 Enter,
전체 건반 시험 연주는 적용 후 K입니다. 다른 음악을 동시에 연주하지 마세요.

O/Ctrl-O로 DAT 파일을 탐색하고, 파일에 커서를 놓으면 미리보기를 표시합니다.
SCC/SCC+는 파일의 실제 32샘플 파형, FM은 6자 이름, ALG/FB와 4개 오퍼레이터의
엔벨로프 개략도를 보여 줍니다. FM 개략도는 합성한 소리의 실제 파형이 아닙니다.
FM 탐색은 내용이 있는 첫 음색부터 표시하며 좌우로 빈 레코드를 건너뜁니다.
Tab으로 NONBLANK/ALL을 전환하면 0으로 채운 레코드까지 볼 수 있습니다.
방향키 상하로 파일, 좌우로 파일 안의 음색/파형을 바꿉니다. Enter 전에는
현재 뱅크·미저장 표시·Undo를 바꾸지 않습니다. 자세한 조작은 2-1을 참고하세요.

W -> P로 SCC/SCC+ 32종 파형을 8열×4행 타일에서 한눈에 선택합니다.
방향키로 파란 선택 타일을 이동하고 Enter로 현재 슬롯에 적용합니다. 아래에는
전체 파형 이름을 표시합니다. F -> P는 FM 12종을 4열×3행 타일로 보여줍니다.
각 타일에는 이름과 OP1..4 엔벨로프 개략도를 표시하며 방향키로 골라 Enter로
현재 슬롯에 적용합니다. 프리셋 번호와 편집 슬롯 번호는 별개입니다.
Esc 취소와 U/Ctrl-Z Undo,
적용 후 자유 편집·DAT/MUC/VGM 출력이 가능합니다. 기본 프리셋의 종류는 PRESETS.TXT에서 확인하세요.

FM 화면은 파라미터 표와 현재 값/범위, 4개 오퍼레이터 엔벌로프를 표시합니다.
SCC 화면은 파형과 선택한 샘플, 부호 있는 32개 샘플의 전체 수치를 표시합니다.
하단 아이콘은 키보드 단축키 안내이며 마우스 버튼이 아닙니다.
K 건반 화면은 대응 키, 현재 음 이름·옥타브, 흰건반/검은건반 발음을 표시합니다.
편리한 조작은 USABILITY.txt에서 확인하세요.

1. 실행 환경

  MSX-DOS2 또는 호환 Nextor 환경
  0100h..D5DFh 사용 가능 TPA, D5E0h 위에 최소 512바이트의 스택 여유
  FM 직접 시험 연주: MAKOTO YM2608, I/O 14h..17h
  SCC/SCC+ 건반 연주: 255 자동 탐색 또는 알고 있는 BIOS 슬롯 ID

탐색 화면과 FM/SCC 프리셋 미리보기용으로 16KiB USER 매퍼 세그먼트 하나를 예약합니다.
기존 512KiB 메모리 안에서 사용하며 추가 RAM 카트리지는 필요하지 않습니다.
종료할 때 세그먼트를 반환합니다. 예약할 여유가 없으면 O 탐색은 사용할 수 없지만
기본 편집과 L 파일명 입력은 계속 사용할 수 있고 FM/SCC의 P는 번호 선택으로 동작합니다.
CPU 속도를 바꾸지 않습니다. SCC+는 BIOS 슬롯 접근을 사용하며 반환 후 CPU
페이지 슬롯과 매퍼 선택 상태를 유지합니다.
그래픽 모드에서는 SCREEN 2로 전환하고 종료 시 원래 화면 모드와 BIOS 색을
복구합니다. 기존 화면의 픽셀 자체를 보존하는 것은 아닙니다. 팔레트는 별도로
변경하지 않습니다. 초기 스택이 D7E0h보다 낮으면 버퍼에 쓰기 전에 종료합니다.
폰트/파형의 무손실 압축으로 0.12와 같은 TPA/스택 경계를 유지합니다.
탐색 화면과 FM/SCC 프리셋 화면은 매퍼에 보관한 오버레이를 필요할 때 복원합니다.
별도의 오버레이 파일이나 MD5 기능은 사용하지 않습니다.


  A>MUCVOICE
  A>MUCVOICE /TEXT

화면의 * 표시는 해당 뱅크에 DAT로 저장하지 않은 변경이 있다는 뜻입니다.
오른쪽 위 F* / W*는 현재 보이지 않는 쪽까지 두 뱅크의 미저장 여부를 나타냅니다.
FREE는 현재 뱅크의 빈 슬롯 수입니다. 종료 확인도 FM/SCC/양쪽을 구분합니다.
기본 FM 뱅크의 1번 INIT은 시험용 음색입니다. 나머지는 무음 초기값입니다.
기본 SCC 뱅크에는 0번 무음 파형이 하나 있습니다.

2. 공통 명령

그래픽 화면: Tab/Shift-Tab은 다음/이전 항목, Ctrl-Tab은 FM/SCC 전환입니다.
[와 ]는 이전/다음 번호입니다. F/W로도 뱅크를 바꿀 수 있습니다.
FM은 화살표로 ALG/FB 또는 OP1..4의 항목을 선택하고 +/-로 조절합니다.
SCC는 좌우로 32개 샘플 중 하나를 선택하고 상하 또는 +로 값을 조절합니다.
SCC의 -는 음수 입력을 시작하므로 감소는 아래 커서키를 사용하세요.
커서로 숫자를 바꾸는 기능(파형 샘플 값, 건반 모드의 옥타브)은 같은 규칙입니다.
상하 커서키를 길게 누르면 값의 증감 폭이 1 -> 2 -> 3 -> 4로
한 단계씩 부드럽게 커집니다. 60Hz에서는 약 0.75초부터 2, 1.5초부터 3,
2.5초부터 4씩 조정하며 더 커지지 않습니다. 50Hz에서는 약 0.9초/1.8초/3초입니다.
이전 1->4->16 급가속은 제거했습니다. 파형 편집의 키 반복 시작/주기는 기존 BIOS 설정을
사용하며, 짧게 누르면 1씩 조정합니다. 키를 떼거나 방향을 바꾸거나 다른 명령을
입력하면 가속은 초기화됩니다. 상하를 동시에 누르면 가속하지 않습니다.
샘플 값은 -128..127, 옥타브는 2..6에서 멈추며 반대쪽 끝으로 넘어가지 않습니다.
Shift+상하 커서키는 두 기능 모두 미세 조정입니다. 오래 눌러도 항상 1씩 조정하며, 이미
가속된 상태에서도 Shift를 누르면 미세 조정으로 바뀝니다. Shift를 떼고 커서키를
계속 누르면 1부터 다시 시작해 2 -> 3 -> 4로 가속하므로 갑자기 값이 뛰지 않습니다.
FM의 +/- 및 SCC의 +는 1씩 조정합니다. FM의 항목 이동과 입력창의 텍스트
커서 이동에는 가속을 적용하지 않습니다. 파형 편집에서 U는 기존처럼
직전 한 단계의 수정을 되돌립니다. 길게 누른 전체 조정을 한 번에 되돌리는 기능은
아닙니다. 건반 옥타브는 시험 연주 상태이므로 뱅크와 Undo를 변경하지 않습니다.
파형 키 반복은 BIOS를 사용합니다. 건반 모드는 직접 키 스캔으로 최초 누름 후
24틱부터 6틱 간격으로 반복하며, 두 모드의 증감 폭과 Shift 규칙은 공통 코드입니다.
선택한 칸에서 숫자를 치면 새 값으로 직접 편집합니다. F2/E/Enter로 시작하면
현재 값이 전체 선택되므로 즉시 교체하거나 좌우로 커서를 옮겨 고칠 수 있습니다.
숫자 편집 중 상하도 공통 1->2->3->4 / Shift=1 규칙으로 값을 조정합니다.
Enter 적용, Tab 적용 후 다음 칸, Esc 취소입니다. 범위를 벗어나면 빨간색으로
표시하고 편집을 유지합니다. 수정해 다시 적용하거나 Esc로 취소하세요.
적용 전에는 뱅크·미저장 표시·Undo·그래프를 바꾸지 않습니다. 선택값 요약과
그래프는 마지막 적용값이며, 커서가 있는 숫자 칸만 현재 입력 초안입니다.
I(번호), C(복사 대상), SCC의 K(슬롯)도 화면 안에서 입력합니다.
P는 FM 12종 엔벨로프 타일 또는 SCC 32종 파형 타일 선택 화면을 엽니다.
N(이름)은 현재 이름을 전체 선택해 보여 줍니다. 메인 Esc는 종료하지 않습니다.
입력창 취소는 편집 데이터와 Undo를 유지합니다. 입력창은 최대 63자를 받고,
추가 문자는 무시합니다. 각 기능의 이름/숫자/파일명 제한은 별도로 검사합니다.
편집 중 좌우는 커서 이동, Home은 맨 앞, Ctrl-E는 맨 끝, Ctrl-A는 전체 선택입니다.
커서 위치에 글자를 삽입하며 Backspace는 앞 글자, Del은 현재 글자를 지웁니다.
Ctrl-U는 전체 삭제, Ctrl-C/X/V는 입력 전체 복사/잘라내기/붙여넣기입니다.
클립보드는 실행 중 MUCVOICE 내부 전용이며 macOS/Windows 클립보드와 연동하지
않습니다. 부분 구간 선택은 지원하지 않습니다. 너무 긴 붙여넣기는 잘라 넣지 않고
거부합니다. GUI의 Ctrl-C는 DOS 강제 종료가 아닙니다.
이 편집 키는 SCREEN 2 입력창 기준입니다.
/TEXT 입력은 DOS의 콘솔 편집 기능을 사용합니다.
마우스는 지원하지 않습니다.

  F  YM2608 FM 뱅크로 전환
  W  SCC+ 뱅크로 전환
  I  음색/파형 번호 선택 (0..255)
  E  파라미터 또는 파형 샘플 편집
  P  내장 프리셋 선택 (FM: 0..11 엔벨로프 타일, SCC: 0..31 파형 타일)
  C  현재 레코드를 다른 번호로 복사 (Y 확인 필요)
  U  마지막 레코드 편집 한 번 되돌리기
  O  DAT 파일 탐색과 미리보기 (Ctrl-O도 동일; /TEXT에서는 파일명 입력)
  L  현재 디렉토리의 8.3 파일명을 입력해 DAT 불러오기
  T  TFI 한 개를 현재 FM 음색 번호로 가져오기 (자세한 내용 TFI.txt)
  R  MUC의 FM 음색 또는 SCC 파형을 선택한 뱅크의 원래 번호에 병합
  G  VGM의 YM2608 FM 음색 또는 SCC/SCC+ 파형을 빈 슬롯에 가져오기
  B  선택한 뱅크의 정의된 슬롯 전체를 정의 전용 MUC로 내보내기
  S  현재 뱅크를 DAT로 저장 (기존 파일 교체는 Y 확인)
  D  FM 슬롯을 비우거나 SCC 파형을 삭제
  X  현재 FM 음색+시험곡 또는 현재 SCC 파형 정의 하나를 MUC로 저장
  V  선택한 음색을 시험 연주하는 VGM 파일 출력
  A  MAKOTO FM1 단음 시험 연주
  K  현재 FM 음색/SCC+ 파형의 건반 시험 연주 (KEYBOARD.txt 참고)
  Q  종료 (미저장 변경이 있으면 Y 확인 필요)

F/W 전환은 번호를 유지합니다. 두 뱅크의 수정 여부는 따로 관리합니다.
Undo는 1단계입니다. 다른 뱅크에서 마지막으로 편집했다면 그 뱅크/번호로
돌아갑니다. DAT 읽기와 일괄 가져오기는 같은 뱅크의 Undo만 지웁니다.
DAT 저장은 같은 뱅크의 Undo도 유지합니다. 저장 후 Undo하면 저장한 레코드와
실제로 달라질 때만 미저장 표시가 켜집니다.
예를 들어 FM 편집 뒤 SCC DAT를 저장해도 FM의 U는 남습니다. Undo 자체는
뱅크마다 여러 단계가 아니라 프로그램 전체의 최근 레코드 편집 1단계입니다.

L 및 저장/가져오기/내보내기 입력창은 현재 디렉토리의 8.3 파일명만 받습니다.
O의 DAT 탐색은 하위 폴더도 지원합니다. 입력창에서는 영문/숫자/_/-와 확장자용
점을 사용할 수 있으며 드라이브, 경로, 와일드카드, 장치명은 받지 않습니다.
예: VOICE.DAT, PATCH001.DAT, WAVE.VGM

L/S가 성공하면 뱅크별로 DAT 파일명을 기억합니다. 다시 S를 누르면 화면 입력창에
그 이름이 들어 있으며 Enter로 재사용하거나 편집할 수 있습니다. /TEXT에서는
빈 답변 뒤 Enter로 기억한 이름을 사용합니다. 프로그램 종료 후에는 기억하지 않습니다.
O로 읽은 뒤에는 해당 뱅크의 기억한 이름을 비웁니다. 다음 S/Ctrl-S에서 현재 DOS
디렉토리에 저장할 이름을 새로 입력하세요. 다른 뱅크의 기억한 이름은 유지합니다.

S는 기존 파일 교체 시 반드시 Y/N을 묻습니다. 임시 파일에 전부 쓰고 닫은 뒤
다시 읽어 메모리와 바이트 단위로 비교합니다. 검증 후 기존 파일은 백업 이름으로
옮기고 임시 파일을 최종 이름으로 바꿉니다. 디스크 버퍼 반영까지 확인한 뒤 백업을
정리하고 미저장 표시를 지웁니다. 설치 실패 시 기존 이름으로 복원을 시도합니다.
현재 경로의 MV$TEMP.$$$ / MV$BACK.$$$가 이미 있으면 덮어쓰지 않고 중단합니다.
전원 차단·매체 고장까지 원자성을 보장하는 파일시스템은 아닙니다. 복구 파일이
남았다는 안내가 나오면 다른 저장을 하기 전에 DOS에서 확인하세요. USABILITY.txt 참고.

GUI 단축키: Ctrl-O=DAT 탐색, Ctrl-Z=Undo, Ctrl-S=저장, Ctrl-Shift-S=다른 이름 저장.
Ctrl-S는 해당 뱅크에서 이미 성공한 읽기/저장의 이름이 있으면 파일명과 교체 질문을
다시 묻지 않고 그 파일에 저장합니다. 임시 파일·재읽기·검증·복구 절차는 S와 같습니다.
아직 이름이 없으면 이름을 묻습니다. Ctrl-Shift-S는 빈 파일명으로 시작하며 기존
파일 교체는 확인합니다. 기존 S의 이름 편집/교체 확인 동작도 유지합니다.

B/X/V의 MUC/VGM 출력은 계속 새 파일 생성만 지원합니다. 파일을 못 찾은 경우는
File not found, 기존 출력 파일 때문에 거부한 경우는 File exists로 구분합니다.
그 밖의 DOS 오류는 코드도 표시합니다. 읽기 전용 DAT는 새 이름으로 저장하세요.

불러올 DAT는 별도 버퍼에서 크기/형식을 확인한 뒤 적용합니다. 읽기, 닫기,
검증에 실패하면 현재 뱅크를 유지합니다. 기존 변경을 버리는 것은 확인을
받습니다. 디스크를 읽는 도중 전원을 끄거나 매체를 빼지 마세요.

2-1. DAT 파일을 파형으로 고르기

먼저 F 또는 W로 읽을 뱅크를 고른 뒤 O/Ctrl-O를 누릅니다. 현재 DOS 디렉토리에서
시작하며 폴더와 .DAT 파일만 표시합니다. 상하로 커서를 움직이면 미리보기를
자동으로 갱신합니다. 목록 끝을 넘으면 다음/이전 묶음으로 이동합니다.
Enter로 폴더에 들어가고 Backspace로 상위 폴더로 갑니다. 탐색 중이나 취소 후에도
DOS의 현재 드라이브/디렉토리는 바뀌지 않습니다. 다른 드라이브를 보려면 DOS에서
드라이브를 바꾼 후 실행하세요. 긴 파일명 대신 DOS의 8.3 이름을 표시합니다.

W에서는 SCWD 파일의 전체 길이·헤더·버전·ID 순서·CRC32를 검사한 뒤 실제 파형을
표시합니다. 한 파일에 파형이 여러 개라면 좌우로 레코드를 바꾸고 표시된 ID를
확인하세요. 희소 ID는 파일에 실제로 정의된 순서대로 이동합니다.
F에서는 정확히 8,192바이트인 FM DAT에서 내용이 있는 첫 음색을 표시합니다.
6자 이름, ALG/FB와 4개 오퍼레이터의 엔벨로프 개략도를 함께 볼 수 있습니다.
NONBLANK에서는 좌우로 내용이 있는 레코드만 이동합니다. Tab으로 ALL을 선택하면
전체 0..255번을 볼 수 있고 다시 Tab으로 NONBLANK로 돌아갑니다. 전부 빈 뱅크는
0번을 표시합니다. 이 필터는 편의를 위한 추정이지 발음 여부나 사용 여부 판정이 아닙니다.
32바이트 레코드의 1..25번 바이트 중 0이 아닌 값이 있거나, 26..31번 이름에
ASCII 33..126 문자가 하나라도 있으면 내용이 있는 것으로 취급합니다. 예약 바이트
0은 무시합니다. 의도적인 0/무음 음색도 ALL에서 선택할 수 있으며 필터가 실제
뱅크의 정의 상태(FREE)나 저장 데이터를 바꾸지는 않습니다.
FM 그림은 실제 합성 파형이나 정확한 칩 시뮬레이션이 아닙니다. Space로 불러오기
전에 듣거나, 불러온 뒤 K/A로 확인하세요. 커서 이동만으로 자동 연주하지 않습니다.
폴더, 읽기 실패, 잘못된 형식은 파형 대신 안내를 표시하며 이전 파일의 파형을
남겨 두지 않습니다. 미리보기만으로 파일을 쓰거나 현재 편집 데이터를 바꾸지 않습니다.

Enter는 미리본 한 음색이 아니라 선택한 DAT 뱅크 전체를 읽습니다. 미저장 변경이
있으면 먼저 확인하며, 파일을 다시 검증한 뒤 선택한 FM 또는 SCC 뱅크만 교체합니다.
성공한 읽기는 해당 뱅크의 Undo를 지웁니다. Esc 또는 변경 폐기 확인의 N은
기존 뱅크·미저장 상태·Undo를 유지합니다. 다른 폴더에서 읽은 파일을 현재 DOS
디렉토리의 같은 이름에 잘못 저장하지 않도록, O 로드 뒤 첫 저장은 새 이름을 묻습니다.
TFI/MUC/VGM 가져오기·내보내기는 기존 입력창을 사용합니다. 이 탐색기는 DAT 전용입니다.

3. YM2608 FM 음색 편집

그래픽: F -> 화살표/Tab으로 항목 선택 -> 숫자 입력 -> Enter (또는 Tab)
/TEXT: F -> I -> 번호 -> E -> 오퍼레이터(1..4) -> 항목 -> 값

TFI 가져오기: F -> I -> 대상 번호 -> T -> 파일명.TFI -> Y
기존 음색 하나만 교체하며 뱅크의 다른 음색은 유지합니다. TFI 원본 파일은
수정하지 않습니다. 가져온 뒤 U로 되돌릴 수 있고 S로 새 DAT를 저장합니다.
긴 원본 파일명은 복사본을 BASS.TFI 같은 DOS 8.3 이름으로 바꾸어 넣으세요.
SSG-EG 활성 음색은 기존 DAT에 해당 설정을 담을 수 없으므로 경고와 확인 후
SSG-EG를 제외한 값만 가져옵니다. 원음과 같다고 보장하지 않습니다.

  항목 번호   이름   범위
  0           AR     0..31
  1           DR     0..31
  2           SR     0..31
  3           RR     0..15
  4           SL     0..15
  5           TL     0..127
  6           KS     0..3
  7           ML     0..15
  8           DT     0..7 (칩의 원시 detune 코드)
  9           AM     0..1

/TEXT에서는 E에서 오퍼레이터 0을 선택하면 0=ALG, 1=FB를 편집합니다.
그래픽에서는 맨 위 ALG/FB 행을 선택합니다. 둘 다 0..7입니다.
하단 엔벨로프는 AR/DR/SL/RR의 변화를 보여주는 개략도입니다. 실제 칩의 시간,
출력 진폭 또는 모든 EG 파라미터를 시뮬레이션한 곡선은 아닙니다.
TL은 값이 클수록 작게 들립니다. 알고리즘에 따라 캐리어/모듈레이터가 다르니
큰 음량으로 시험하지 마세요. N은 0..6자의 ASCII 음색 이름을 설정합니다.

FM DAT는 기존 MUCOM88 형식인 32바이트 x 256개 = 8,192바이트입니다.
OP1/OP3/OP2/OP4의 실제 저장 순서와 논리 OP1..4 표시를 구분합니다.
수치 하나를 바꾸어도 다른 필드와 예약 비트를 유지합니다. 읽기/저장만 하면
파일이 바이트 단위로 동일합니다. 원래 이름의 CP932 바이트는 보존하지만
콘솔에서 ASCII 밖의 문자는 점으로 표시합니다. N으로 바꾸면 ASCII가 됩니다.

X는 선택한 음색을 @%번호 원시 25바이트 인라인 형식으로 포함한 시험 MUC를
출력합니다. 외부 VOICE.DAT 없이 현재 MUC2MUB/MUCPLAY에서 컴파일할 수 있습니다.
AM 등 일반 음색 정의에서 손실될 수 있는 값도 원시 형식으로 전달합니다.
MUC/VGM 출력은 DAT 뱅크 저장이 아니므로 * 표시는 지우지 않습니다.

R은 @N 여러 줄, @N:{...}, @%N 원시 형식의 FM 정의를 가져옵니다.
파일 전체를 검사하고 Y로 확인한 뒤 같은 번호의 슬롯을 교체합니다. 다른 슬롯은
보존합니다. 여러 음색을 한 번에 병합하므로 성공 시 같은 뱅크의 Undo는 초기화됩니다.
중복 번호, 범위 초과, 잘린 정의나 읽기/닫기 오류가 있으면 전혀 적용하지 않습니다.
B는 정의된 모든 FM 슬롯을 번호 순서대로 @%N 형식으로 출력합니다. 시험곡은
붙이지 않으므로 악보의 음색 정의 부분에 넣거나 R로 다시 가져올 수 있습니다.
초기에는 1번 INIT만 정의되어 있으며, 편집/복사/TFI/MUC 가져오기로 슬롯을
정의합니다. DAT에는 사용 여부 비트가 없으므로 DAT를 읽으면 256개 모두 정의된
것으로 취급합니다. DAT를 저장한 파일을 다시 읽을 때도 같은 규칙입니다.
DAT를 불러온 뒤 새 VGM 음색을 넣으려면 I로 교체할 슬롯을 고르고 D -> Y로
명시적으로 비워 주세요. U로 취소할 수 있습니다. 이후 G는 그 빈 슬롯부터
사용하므로 재실행할 필요가 없습니다. D 자체는 기존 32바이트를 지우지 않고
사용 플래그만 끄며, 새 음색을 가져올 때 해당 레코드가 바뀝니다. 빈 슬롯 목록을
보존하려면 B로 MUC도 저장하세요. DAT에 임의의 새 포맷을 추가하지 않았습니다.
FM 파라미터 25바이트를 원시 형식으로 보존하며, DAT 전용 레코드 첫 바이트는
MUC에 들어가지 않습니다. 자세한 문법, 이름 처리와 제한은 MUCIO.txt를 참고하세요.

A는 MAKOTO 확인 질문 뒤 FM1에 약 440Hz를 직접 연주합니다. 키를 누르면
키오프와 TL 음소거를 수행합니다. FM1 음색/공통 LFO 등 칩 상태를 바꾸므로
다른 음악을 완전히 중지한 뒤 사용하세요. 기존 칩 레지스터 상태 복원이나
다른 플레이어와의 동시 연주는 지원하지 않습니다. 장치 무응답 대기는
상한이 있습니다. 강제 리셋, 전원 차단, 물리적 고장까지 복구하지는 못합니다.

V는 YM2608 VGM 1.71을 출력합니다. 기본 클록 7.9872MHz, 2초 연주 후
키오프, 0.5초 감쇠 후 음소거합니다. MAKOTO 8MHz와의 미세 차이는 허용합니다.

4. SCC+ 파형 편집

그래픽: W -> 좌우/Tab으로 샘플 선택 -> 숫자/- 입력 -> Enter (또는 상하 조절)
/TEXT: W -> I -> 번호 -> E -> 샘플 번호(0..31) -> 값(-128..127)

P는 현재 번호에 선택한 기본/게임풍 파형을 만듭니다.
  0 무음 / 1 톱니 / 2 삼각 / 3 사각 / 4 사인 / 5 25% 펄스 / 6 12.5% 펄스
  7 오르간 / 8 리드 / 9 베이스 / 10 홀로우 / 11 금속성
  12..31 역톱니·여러 펄스 폭·계단·부드러운 기본파·배음 합성 등 추가 20종
화면의 파형을 방향키로 고르고 Enter로 적용합니다. Esc는 선택을 취소합니다.
SCC와 SCC+에 같은 32샘플을 사용합니다. 특정 게임의 원본 채취 파형은 아닙니다.
FM에서도 P로 순음·피아노·오르간·베이스·브라스·플럭·기타·벨·플루트·리드·패드
등 12종을 적용합니다. 기존 음색을 교체하므로 필요하면 먼저 저장하거나 C로 복사하세요.
프리셋 목록, 현재 슬롯/프리셋 번호의 차이와 출처 조건은 PRESETS.TXT에 있습니다.

아직 없는 번호는 E/P/C로 정의할 수 있습니다. D는 현재 파형을 삭제하며
마지막 하나는 지우지 못합니다. Undo로 삭제한 파형을 복구할 수 있습니다.

SCC DAT는 SCWD v1이며 FM VOICE.DAT와 전혀 다른 파일입니다.
헤더 16바이트 + 레코드 34바이트 x 1..256개, 최대 8,720바이트입니다.
오름차순 ID, 버전, 예약 필드, 파일 길이와 CRC32를 검사합니다. 파형 이름은
이 형식에 없으므로 SCC 이름 편집은 지원하지 않습니다.

V는 선택한 파형을 SCC+ 채널 1에서 시험하는 VGM 1.71을 생성합니다.
재생기는 K052539/D2 명령을 지원해야 합니다. 2초 뒤 채널을 끕니다.
K는 현재 파형을 SCC+ CH1에 올려 직접 건반 연주합니다. 카트리지의 정확한
255로 자동 탐색하거나 알고 있는 BIOS 슬롯 ID를 지정하세요. 아무 슬롯이나 추측해서 지정하지 마세요. 자세한 조건은 KEYBOARD.txt.

SCC 화면에서 R은 MUC의 @W번호 = { 32개 샘플 } 정의를 가져옵니다.
성공하면 파일의 첫 파형 정의를 선택합니다. B로 내보낸 뱅크를 다시 읽으면
0번 무음 파형이 첫 정의일 수 있으니, K로 들어보기 전에 I로 원하는 번호를
선택하세요. 무음 파형이 선택됐다는 이유로 건반 모드가 고장난 것은 아닙니다.
각 샘플은 -128..127의 부호 있는 10진수이며 번호는 0..255입니다.
X는 선택한 정의된 파형 하나, B는 정의된 모든 파형을 같은 문법으로 저장합니다.
FM/SCC 혼합 파일에서는 선택한 뱅크만 병합합니다. 검증 또는 확인 취소 시
기존 뱅크를 보존하며 성공한 일괄 병합은 같은 뱅크의 Undo를 초기화합니다.
SCWD DAT는 정의된 파형 ID 목록까지 보존합니다. 자세한 내용은 MUCIO.txt 참고.

SCC MUC 출력은 파형 정의의 교환용이며 그 자체만으로 완성된 악보는 아닙니다.
곡에서 사용하려면 지원하는 파트·파형 문법과 연주 명령을 함께 작성하세요. SCC DAT를 FM의
VOICE.DAT 대신 지정하면 안 됩니다. JSON/WAV 가져오기는 기존 PC/browser
scc_tools를 사용하세요. DOS판에서도 그래프를 보면서 샘플 값을 편집할 수 있습니다.

5. VGM 가져오기와 확인

0.7의 G 명령은 비압축 VGM에서 선택한 뱅크의 음색을 추출합니다. 기존 정의는
덮어쓰지 않고 현재 번호부터 빈 슬롯에 추가하며 완전 동일한 데이터는 합칩니다.
전체 검사 후 Y를 눌러야 반영되며 성공 시 같은 뱅크의 Undo를 초기화합니다.
FM DAT를 불러온 뒤에는 0.10의 D -> Y로 새 음색을 넣을 슬롯을 비울 수 있습니다.
SSG-EG/LFO 등 DAT에 담지 못하는 설정은 확인을 요청합니다. 원본 음색 이름,
작곡 시의 TL, 시간에 따른 변화는 복원하지 않습니다. VGMIO.txt를 참고하세요.
VGZ는 PC에서 압축 해제해야 하며 DAC 스트림 제어 명령은 안전하게 거부합니다.



MUCVOICE는 음색 편집 도구입니다. 음악 전체의 편집·컴파일·연주는
MUCEDIT/MUCPLAY/MUC2MUB/MUBPLAY를 사용하세요.
