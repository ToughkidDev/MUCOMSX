MUCVOICE SCC/SCC+ detection reference (2026-10-11)

The keyboard acquisition strategy references MSX VGMPlay's SCC/SCCPlus
drivers by Laurens Holst (Grauw): RAM exclusion, reversible waveform
readback, mode/bank selection and return to conventional default banks.
MUCVOICE uses BIOS inter-slot accesses rather than VGMPlay's direct slot
mapping, and retains its independent single-voice editor implementation.

MUCVOICE 0.12 factory preset tables are independent original synthesis
definitions (the four existing elementary SCC shapes retain their bytes).
They are not ripped Konami game waves or Yuzo Koshiro sample patches.
The separately licensed YK2MML original DAT reference copies are local
reference assets only, excluded from the COM and standalone package.py.
See PRESETS.TXT and reference/YK2MML/LICENSE.TXT before using those assets.
