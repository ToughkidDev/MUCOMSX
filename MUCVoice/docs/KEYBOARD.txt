MUCVOICE v0.5beta — 편집한 음색을 건반으로 들어보기
2026-10-15

v0.5beta는 P/O 미리듣기에서 같은 음색과 SCC 장치 설정을 재사용합니다. 키 해제 시
음소거하고 다음 음의 음량/음정을 복원하며, 음색 변경과 종료에는 설정을 갱신합니다.
K 건반 배열과 조작은 그대로입니다.

0.17 추가: P 프리셋 화면과 O DAT 브라우저에서 C D E F G A B는 C4..B4입니다.
Shift를 함께 누르면 C5..B5이며 높은 도는 Shift+C입니다. 대소문자/Caps Lock은
음높이에 영향이 없습니다. 실제 키를 누르는 동안 발음하며 놓으면 정지합니다.
새 키를 누르면 그 음으로 바뀌는 단음 연주입니다. 이동/적용/취소 및 180틱 후
안전 정지하고, 편집 데이터와 Undo는 바꾸지 않습니다. 아래 K 모드 배열은 그대로입니다.
Enter/Esc로 선택 화면을 나갈 때는 누르고 있던 음 키를 놓으면 다음 화면으로 진행합니다.
0.17.1은 폴더·잘못된 DAT의 미발음 키까지 해제를 기다립니다. 대기 중 PLAY는 지워집니다.

P 프리셋 선택 화면과 O DAT 브라우저에서는 Space로 적용 전 A4
미리듣기/정지를 토글합니다. 다른 키 또는 180틱(약 3~3.6초) 후에도 정지하며
뱅크·Undo는 바꾸지 않습니다. 이것은 아래 K 건반 모드와 별개의 조작입니다.
K 화면에서는 기존대로 Space를 누르는 동안 음소거합니다.
===========================================

K는 현재 선택한 음색을 MSX 키보드로 직접 들어보는 단음 건반 모드입니다.
P로 FM/SCC 내장 프리셋을 적용한 뒤에도 바로 K로 시험할 수 있습니다.
DAT로 저장하거나 MUC를 컴파일할 필요 없이, 방금 편집한 값으로 발음합니다.
TFI/MUC/VGM에서 가져온 음색도 동일합니다. 외부 MIDI 건반 입력은 아닙니다.
건반 모드에서는 BIOS 키 클릭을 잠시 끕니다. 긴 키 유지의 반복 클릭이 특히
조용한 FM 음색을 덮지 않게 하기 위한 처리입니다. 돌아올 때는 사용자의 원래
CLIKSW 값을 그대로 복원하며 DOS 종료 콜백도 같은 정지 경로를 사용합니다.

1. 시작하기

FM: F -> 원하는 번호/파라미터 편집 -> K -> MAKOTO 확인 Y
SCC/SCC+: W -> 파형 편집 또는 P로 파형 생성 -> K -> 255(자동) 또는 BIOS 슬롯 번호 -> Y
그래픽 모드는 확인 답변 뒤 Enter, /TEXT는 각 명령 뒤에도 Enter를 누릅니다.
선택한 SCC 파형이 정의되지 않았다면 먼저 E/P/C 등으로 정의하세요.
스피커 볼륨은 낮게 시작하세요. FM TL과 SCC 파형에 따라 음량이 크게 다릅니다.

2. 건반

SCREEN 2에는 8개 흰건반과 5개 검은건반을 실제 피아노 배치로 그립니다.
건반의 영문자는 누를 MSX 키입니다. 발음 중인 흰건반은 청록색, 검은건반은
붉은색으로 표시합니다. 옆 상태 표시에는 C#4, A4 등의 현재 음과 SOUND가
나오고, 키오프 시 READY로 돌아갑니다. READY는 키를 놓았다는 의미이며 FM
엔벨로프의 잔향은 남을 수 있습니다. Space와 종료는 잔향도 음소거합니다.
현재 선택한 음색 번호/이름과 미저장 상태, FM 파라미터 또는 SCC 파형도 위에
남겨 놓았습니다. FM 옆에는 읽기 전용 미리보기임을 표시합니다.
기존 MUBVISPLAY 3x5 폰트를 유지하며 /TEXT는 문자 안내 방식 그대로입니다.

  키   Z  S  X  D  C  V  G  B  H  N  J  M  ,
  음   C C#  D D#  E  F F#  G G#  A A#  B  C(다음 옥타브)

위/아래 화살표: 옥타브 2..6, 시작은 4. 짧게 누르면 한 단계입니다.
길게 누르면 파형 편집·숫자 편집과 같은 1 -> 2 -> 3 -> 4 증감 규칙을 사용합니다.
60Hz에서 약 0.75초/1.5초/2.5초에 단계가 바뀌며 50Hz에서는 0.9초/1.8초/3초입니다.
최대 증감 폭은 4이고 옥타브 자체는 2..6에서 멈춥니다. 반복 속도는 올리지 않습니다.
Shift+위/아래는 오래 눌러도 항상 1씩 미세 조정합니다. 가속 중 Shift를 누르면
미세 조정으로 바뀌며, Shift를 떼면 1부터 다시 가속합니다. 방향 전환/키 해제는
유지 시간을 초기화하며, 상하 동시 입력은 옥타브를 바꾸지 않습니다.
최초 누름 후 24틱(60Hz 약 0.4초) 대기, 이후 6틱(약 0.1초) 간격으로 반복합니다.
옥타브 변경은 건반 모드의 임시 설정이며 음색 뱅크/미저장 상태/Undo는 그대로입니다.
마지막 쉼표 키는 다음 옥타브 C이므로 전체 범위는 C2..C7입니다.
Space: 누르는 동안 강제 음소거. 놓으면 아직 누르고 있는 음을 다시 발음합니다.
Esc / STOP / Ctrl+C: 소리를 멈추고 편집 화면으로 돌아갑니다.
종료할 때는 누르고 있던 건반을 모두 놓아야 편집 화면으로 돌아갑니다.

한 번에 한 음만 연주하며 여러 키를 누르면 가장 낮은 음이 우선합니다.
낮은 음을 놓으면 남은 높은 음으로 바뀝니다. 키를 계속 누른 동안 불필요하게
재발음하지 않습니다. MSX 물리 키 매트릭스의 동시 입력 제한은 그대로 있습니다.
일반 MSX QWERTY 물리 배열 기준입니다. 다른 키보드 레이아웃에서는 위치가 다를 수
있습니다. 오디오 반응은 VBlank 단위이며 USB/MIDI 벨로시티 입력은 없습니다.

FM은 키를 놓으면 key-off하여 RR 등 음색의 잔향을 들려줍니다. Space와 종료는
TL까지 음소거합니다. SCC+는 키를 놓는 즉시 정지하며 별도 엔벨로프는 없습니다.
FM은 MAKOTO FM1, SCC+는 CH1/고정 음량 12를 사용합니다.
건반 중 파라미터 편집은 하지 않습니다. 돌아와서 수정한 뒤 K로 다시 확인하세요.
DAT 데이터, 정의 여부, Undo와 미저장 표시는 연주만으로 바뀌지 않습니다.

3. SCC/SCC+ 슬롯 지정 (2026-10-11 개선)

입력 값은 BIOS 형식의 10진수 슬롯 ID입니다.
  자동 탐색: 255 (전체 SCC+ 먼저, 없으면 전체 SCC)
  일반 비확장 슬롯: 0..3 (알고 있는 실제 장착 위치)
  확장 슬롯: 128 + 기본 슬롯 + 4 x 보조 슬롯
  MegaFlashROM SCC+ SD: SCC가 보조 슬롯 1에 있으므로 기본 슬롯 1이면 133,
                       기본 슬롯 2이면 134입니다.
SCC 슬롯이 아닙니다. RAM 슬롯은 검사 후 거부합니다.

2026-10-12 빌드에서는 일반 SCC 경로의 SCC-I 모드 선택을 00h로 교정했습니다.
SCC+ 경로의 20h와 구분하며, 자동 탐색의 SCC+ 우선 순서는 바꾸지 않았습니다.

255는 BIOS EXPTBL에 등록된 슬롯/서브슬롯 전체를 탐색합니다. 정확한 위치를
알면 수동 지정도 유지됩니다.  8000h/A000h의 원복 가능한
2패턴 검사로 RAM을 거부하고 파형 RAM을 검사합니다. 변형 레지스터는 읽지 않으며
시험 파형은 복원합니다. 임의 주변기기의 모든 쓰기 부작용까지 보장하지는 않습니다.
다른 음악을 먼저 중지하고 takeover 확인에 동의하세요. SCC+는 B800h/B8A0h,
일반 SCC는 9800h/9880h를 사용합니다. 같은 DAT의 32샘플 파형으로 양쪽 모두
CH1 단음 연주할 수 있습니다. 일반 SCC의 CH4/5 공유 제약은 CH1에 영향 없습니다.

SCC+ 전체 5채널을 음소거하고 변형 레지스터를 초기화한 뒤 현재 파형을 올립니다.
종료 시 5채널을 끄고 SCC+는 B000h=3, SCC는 9000h=2, 이후 BFFFh=0으로 돌립니다. 이전 음악/파형/임의
카트리지 뱅크 설정을 복원하는 기능은 아닙니다. 카트리지가 유휴 상태이며 위 기본
뱅크/모드로 돌아가도 되는 환경에서만 사용하세요. 다른 프로그램과 동시 연주하지
마세요. CPU 페이지 슬롯 및 메모리 매퍼 선택 값은 보존하고 추가 RAM을 예약하지
않습니다. 플래시 설정이나 디스크 영역을 쓰는 기능도 없습니다.

4. 사용 제한

FM도 FM1 음색 및 공통 설정을 바꾸므로 이전 칩 상태는 복원하지 않습니다.
지원 음색은 기존 25바이트 DAT FM 파라미터와 32바이트 SCC 파형입니다.
FM SSG-EG/하드웨어 LFO 등 DAT에 없는 설정을 새로 합성하지 않습니다.
원본 곡 전체의 엔벨로프·볼륨 자동화와 같게 재현하는 기능이 아닙니다.

정상 종료와 DOS 종료 훅에서 음소거합니다. 리셋/전원 차단/카트리지 물리 고장은
복구 범위 밖입니다. 강제 DOS 종료 시에는 눌렀던 키를 놓아 DOS 입력을 피하세요.
