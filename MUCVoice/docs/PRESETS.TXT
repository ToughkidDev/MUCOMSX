MUCVOICE v0.5beta — FM/SCC factory presets / 2026-10-15
==================================================

P로 현재 뱅크의 프리셋을 선택합니다. F는 FM, W는 SCC/SCC+입니다.
v0.5beta는 같은 음색의 설정과 SCC 장치 정보를 재사용하여 건반 반응을 개선했습니다.
키 해제 시 정지하며 다음 음의 음량/음정을 복원합니다. 선택/모드 변경·오류·종료에는
필요한 설정을 갱신하므로 다른 음색의 데이터가 재사용되지 않습니다.
파일 상하 이동이 여러 개 대기 중이면 마지막 선택 파일을 읽고 검증합니다.
뒤따르는 Space나 Enter는 그 최종 파일에 적용됩니다. 데이터 형식은 그대로입니다.
C D E F G A B: 도레미파솔라시(C4..B4)를 적용 전에 연주합니다. 파일 브라우저도
같습니다. 대소문자/Caps Lock은 무관하며 Shift를 함께 누르면 한 옥타브 위입니다.
높은 도는 Shift+C. 누르면 발음하고 놓으면 정지합니다. 새 건반은 이전 음을
대신하며 한 번에 한 음만 연주합니다. 이동/적용/취소 및 180틱 후에도 정지합니다.
실제 건반을 놓고 다시 눌러야 재발음하므로 BIOS 자동 반복으로 켜지지 않습니다.
Enter/Esc로 선택 화면을 나갈 때는 누르고 있던 음 키를 놓아 주세요. 먼저 소리를
멈추고 키 해제 후 진행하여, 반복 입력이 편집 단축키나 확인 답변으로 넘어가지 않습니다.
폴더나 잘못된 DAT처럼 발음하지 못한 경우도 같은 규칙입니다. 대기 중 PLAY는 지워집니다.
선택한 타일에서 Space를 누르면 적용하지 않고 A4음을 미리 듣습니다. 파일
브라우저에서도 표시 중인 음색을 같은 방법으로 듣습니다. 다시 Space를 누르거나
다른 키로 이동/적용/취소하면 정지하고, 180틱(약 3~3.6초)이 지나도 자동 정지합니다.
Space를 길게 누를 때 BIOS 자동 반복으로 재발음하지 않습니다. 키 클릭 설정도
연주 중에만 잠시 끄고 복원합니다. FM은 MAKOTO FM1, SCC/SCC+는 자동 탐색 CH1을
사용하므로 다른 음악과 동시에 실행하지 마세요. 하드웨어 없음/응답 실패는 NO CHIP,
정상 발음은 우측 상단 C4 PLAY처럼 현재 음을 표시합니다. Space는 A4 PLAY입니다.
뱅크·Undo·현재 슬롯·파일은 그대로입니다.
SCC에서는 32종의 실제 파형을 8열×4행 타일로 보여줍니다. 방향키로 파란 타일을
옮기면 하단에 전체 이름이 표시됩니다. 가장자리에서는 멈추며 줄을 넘지 않습니다.
선택은 다음 P에도 기억됩니다. 타일 번호는 프리셋 번호이지 편집 슬롯 ID가 아닙니다.
FM에서는 12종을 4열×3행 타일로 표시하며 각 타일의 이름과 OP1..4 엔벨로프
개략도를 비교할 수 있습니다. 방향키로 한 칸씩 이동하며 위아래는 같은 열의 타일을
선택합니다. FM 그림은 실제 출력 파형이나 정확한 합성 시뮬레이션이 아닙니다.
Enter로 현재 슬롯에 적용하고 Esc로 취소합니다. 선택 중에는 현재 음색과 Undo를
바꾸지 않습니다. FM은 0..11, SCC는 0..31입니다. /TEXT에서는 둘 다 번호로
입력합니다. 예: W -> I -> 40 -> P -> SINE 타일 선택 -> Enter는 40번 슬롯에
4번 SINE 프리셋을 복사합니다. 다른 슬롯과 다른 뱅크는 바꾸지 않습니다.

적용 후 자유롭게 파라미터/파형을 수정하고 K로 들어보세요. U/Ctrl-Z로 적용 전
레코드와 정의 여부를 되돌립니다. S/Ctrl-S는 DAT 저장, X는 현재 음색 MUC,
B는 정의된 뱅크 MUC, V는 시험 VGM 출력입니다. MUC/VGM 출력은 미저장 표시를
지우지 않습니다. 저장 뒤에도 Undo는 유지됩니다. /TEXT에서는 P 뒤 번호와 Enter.
프리셋 선택을 반복해도 같은 슬롯을 계속 교체합니다. 여러 음색을 보관하려면 먼저
I 또는 [/]로 서로 다른 빈 슬롯을 고르거나 C로 복사하세요.

외부 프리셋 DAT를 그림으로 고르기
--------------------------------
F 또는 W로 뱅크를 선택한 뒤 O/Ctrl-O를 누릅니다. 폴더와 .DAT 파일 목록에서
상하로 커서를 움직이면 파일을 읽어 미리보기를 표시합니다. Enter는 폴더 진입,
Backspace는 상위 폴더, Esc는 취소입니다. DOS의 현재 디렉토리는 바뀌지 않습니다.
SCC 파일은 SCWD 전체 길이/헤더/CRC32를 검사한 뒤 실제 32샘플 파형을 그립니다.
좌우로 뱅크 안의 다른 파형을 확인하며 화면의 ID는 파일에 들어 있는 실제 번호입니다.
FM 파일은 8,192바이트의 VOICE.DAT 형식입니다. 내용이 있는 첫 레코드부터
6자 이름, ALG/FB와 4개 오퍼레이터 엔벨로프 개략도를 보여 줍니다. 실제 출력의
샘플 파형은 아닙니다. NONBLANK에서 좌우는 빈 레코드를 건너뛰며 Tab으로 ALL을
선택하면 0..255 전체를 볼 수 있습니다. 전부 빈 뱅크는 0번부터 표시합니다.
필터는 레코드 바이트 1..25 중 하나라도 0이 아니거나, 이름 바이트 26..31 중
ASCII 33..126 문자가 있으면 내용이 있다고 추정합니다. 예약 바이트 0은 무시합니다.
발음 여부를 검사하는 기능은 아닙니다. 의도적인 0/무음 음색은 ALL에서 볼 수 있고,
뱅크의 정의 플래그나 FREE, 저장할 레코드를 변경하지 않습니다.
파일에 커서를 놓거나 좌우로 보는 동안 현재 뱅크/미저장 상태/Undo는 그대로입니다.
오류 파일이나 폴더에서는 이전 파형을 지우고 안내하며 Space로도 발음하지 않습니다.
커서 이동만으로 자동 발음하지 않습니다. 원하는 음색에서 Space를 누르세요.

Enter는 선택한 한 레코드가 아니라 DAT 전체 뱅크를 읽습니다. 미저장 변경 폐기 확인과
파일 재검증 뒤에만 반영합니다. 필요한 개인 뱅크는 먼저 S로 보관하세요.
O로 읽은 뒤 다음 S/Ctrl-S는 저장 이름을 새로 묻습니다. 탐색한 폴더의 원본에
즉시 덮어쓰는 기능이 아니며 저장 위치는 DOS의 원래 현재 디렉토리입니다.
L은 기존 8.3 파일명 직접 입력을 유지합니다. /TEXT에는 그래픽 미리보기가 없습니다.
파일 이름에 게임명/파형명을 담은 별도 프리셋도 DOS에서는 8.3 이름으로 표시됩니다.
원본·변환·추출 프리셋의 출처와 이용 조건은 해당 폴더의 문서를 함께 확인하세요.

---------------------------------------
  0 SILENT   무음 / 빈 파형에서 시작

0..11은 이전 버전의 실제 파형 바이트를 그대로 유지합니다. 모두 독립 제작한
정적 파형입니다. 특정 Konami 게임의 원본 추출 파형이라고 주장하지 않습니다.
SCC 게임풍 작곡/편집의 시작점이며, 특정 게임의 음량 엔벨로프·비브라토·동적 파형
교체까지 재현하는 것은 아닙니다. 펄스 25/12.5%는 양/음 면적을 균형 있게 구성했습니다.
METAL도 완전한 종소리 녹음이 아니라 정수 배음의 짧은 주기 파형입니다.
SCC 0번은 의도적으로 무음입니다. 정의된 SILENT 슬롯이라도 K에서 소리가 안 납니다.

-----------------------------------------

  1 EPIANO   FM 일렉트릭 피아노풍
  2 PIANO    감쇠하는 밝은 피아노풍
  3 ORGAN    정수 배음 오르간
  4 BASS     직렬 4OP 베이스
  5 BRASS    완만한 어택의 브라스풍
  6 PLUCK    빠르게 감쇠하는 플럭
  7 GUITAR   기타풍 리드/플럭
  8 BELL     높은 주파수 비율의 벨풍
  9 FLUTE    약한 변조의 플루트풍
 10 LEAD     피드백과 약한 detune의 신스 리드
 11 PAD      느린 어택과 릴리스의 패드

모두 이번 프로젝트에서 독립적으로 설계한 기본 악기 프리셋입니다. 고시로 유조나
특정 게임에서 채취한 음색이 아닙니다. SSG-EG·하드웨어 LFO·외부 PCM은 사용하지
않으므로 기존 DAT/MUC에 저장할 수 있습니다. 파라미터는 논리 OP1..4로 설계하고
실제 DAT의 OP1/OP3/OP2/OP4 저장 순서로 직렬화합니다. 피아노/기타/관악기는
음색의 성격을 나타내는 이름이며 실제 악기의 정확한 음향 복제 보증이 아닙니다.
TL은 클수록 작게 들립니다. 프리셋 전환 시 처음에는 스피커 음량을 낮춰 주세요.
PAD는 천천히 발음하므로 아주 짧게 누르면 조용할 수 있습니다.
