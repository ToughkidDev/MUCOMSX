# MUCVOICE v0.5beta — ユーザーガイド

[English](MANUALEN.md)

MUCVOICEはMSX-DOS2/Nextor用の音色エディタです。YM2608のFM音色とSCC/SCC+の32サンプル波形を編集し、DAT・TFI・MUC・VGMから取り込み、音色バンクやインライン定義として保存できます。曲全体の編集・コンパイル・再生にはMUCEDIT・MUCPLAY・MUC2MUB・MUBPLAYを使用してください。

## 1. 導入と動作環境

`MUCVOICE.COM`・`FMVOICE.DAT`・`SCCVOICE.DAT`・`INIT.TFI`をSDやディスクにコピーし、読み書きするDOSディレクトリから起動します。DOS/NextorのシステムファイルやカートリッジROMは付属しません。

MSX-DOS2または互換Nextorが必要です。512KiBメモリマッパー環境を推奨します。0100h〜D5DFhのTPAとD5E0hより上に512バイト以上のスタック領域が必要で、起動時のスタックがD7E0h未満なら起動を拒否します。ブラウザとグラフィカルなプリセット画面用に空き16KiB USERマッパーセグメントを1個確保し、終了時に返却します。確保できない場合も基本編集と`L`によるファイル名指定は使えますが、`O`のブラウザは使えず、`P`は番号選択になります。CPU速度は変更しません。

FM試聴にはI/O 14h〜17hのMAKOTO YM2608、SCC試聴にはSCC/SCC+カートリッジが必要です。編集やファイル変換だけなら音源は不要です。試聴前にほかの音楽を停止してください。音源設定を変更し、以前のプレイヤーの音色や任意のカートリッジバンク設定は復元しません。

```text
A>MUCVOICE
A>MUCVOICE /TEXT
```

標準はSCREEN 2、256×192ピクセルの画面です。`/TEXT`はDOSコンソール入力を使い、コマンドや回答の後にEnterを押します。グラフィカル画面ではコマンドキーが即時に動作し、ファイル名と確認回答はEnterで確定します。終了時は以前の画面モードとBIOSの色を戻しますが、以前の画面のピクセルは復元しません。マウスには対応していません。

## 2. 最初の音色を作る

1. `F`でFM、`W`でSCC/SCC+を選びます。
2. `I`で保存先のスロット番号0〜255を選びます。
3. `P`を押し、矢印でプリセットを選び、Spaceまたは`C D E F G A B`で試聴します。
4. Enterで現在のスロットに適用します。Escなら変更しません。
5. 項目やサンプルを選び、その位置で数値を直接入力します。Enterで確定、Tabで確定して次へ、Escで取消です。
6. `K`で編集した音色を鍵盤演奏します。
7. `S`でDATバンクを保存します。FMとSCCのDATは互換ではないので別の名前を使ってください。

## 3. 主なコマンド

| キー | 操作 |

| I / [ / ] | 番号指定 / 前のスロット / 次のスロット |
| E / F2 / Enter | 現在の値を全選択して編集開始 |
| P | 現在のスロットに内蔵プリセットを選択 |
| N | FM名をASCII最大6文字で変更 |
| C | 現在のレコードを別番号へコピー。Yで確認 |
| U / Ctrl+Z | 最後の1レコード編集を取り消す |

| G | 非圧縮VGMから空きスロットへ音色抽出 |
| B | 現在のバンクの定義済み全スロットをMUCへ出力 |
| X | 現在のFM音色と短い楽譜、またはSCC定義1個をMUCへ出力 |
| S | 名前編集と上書き確認付きでDAT保存 |

Tab/Shift+Tabで次/前の項目、Ctrl+Tabでバンク切替です。FMは矢印で項目選択、`+`/`-`で1ずつ変更します。SCCは左右でサンプルを選び、上下で値を変更します。SCCの`-`は負数入力を開始するため、減少は下矢印を使います。メイン画面のEscでは終了しません。

## 4. 数値入力とUndo

選択位置で直接数字を入力できます。`F2`・`E`・Enterで始めると現在の値を全選択します。入力中の左右は文字カーソル、Homeは先頭、Ctrl+Eは末尾、Ctrl+Aは全選択です。Backspaceは前の文字、Deleteは現在位置の文字、Ctrl+Uは入力全体を削除します。Ctrl+C/X/Vは入力全体のコピー・切取り・貼付けで、PCのクリップボードとは連動しません。部分範囲選択は未対応です。入力バッファは最大63文字で、各項目には別途値や名前の制限があります。

Enterで確定、Tabで確定して次へ、Escで取消です。範囲外なら赤く表示し、入力を継続します。確定するまでは入力欄だけが編集中の値を示し、バンク・グラフ・未保存状態・Undoは最後の確定値のままです。

波形編集・数値入力・鍵盤のオクターブで上下を保持すると、増減幅は1 → 2 → 3 → 4と緩やかに変わります。60Hzでは約0.75秒・1.5秒・2.5秒、50Hzでは約0.9秒・1.8秒・3秒が目安です。Shift併用は常に1刻みです。キー解放・方向変更・別コマンドで加速をリセットし、Shiftを離しても1から再開します。上下限で止まり、反対側へ回りません。項目移動と文字カーソル移動は加速しません。

Undoはプログラム全体で最後の1レコード編集です。各バンクの多段履歴ではなく、定義状態も復元します。DAT保存ではUndoを維持し、読込みや一括取込みではそのバンクが所有するUndoだけを消去します。SCC保存でFM Undoは消えません。矢印保持による変更全体を1操作として戻す機能ではありません。

`*`はDATに未保存の変更、`F*`/`W*`は表示していないバンクも含む未保存状態です。`FREE`は未定義スロット数です。MUC/VGM出力はDAT保存ではないため、未保存表示を消しません。

## 5. プリセットと適用前の試聴

FMは4×3の12タイル、SCCは8×4の32波形です。矢印で選ぶだけでは編集バンクを変更しません。Enterで現在のスロットへコピー、Escで取消です。プリセット番号と保存先スロットは別です。例えばスロット40でSCCプリセット4 SINEを選ぶと、変更するのはスロット40です。

FMには純音・ピアノ・オルガン・ベース・ブラス・プラック・ギター・ベル・フルート・リード・パッド系などを用意しています。SCCには無音・鋸歯・三角・矩形・正弦・各種パルス幅・オルガン/リード/ベース系・階段波・倍音合成波があります。内蔵プリセットは独自合成で、市販ゲームから抽出した波形ではありません。取り込む音色の利用条件は別途確認してください。

SpaceでA4試聴の開始/停止を切り替えます。`C D E F G A B`は保持中にC4〜B4、Shift併用でC5〜B5です。上のドはShift+Cです。大文字/小文字とCaps Lockは音高に影響しません。同時に鳴るのは1音です。音キーの解放、選択移動・適用・取消で停止します。180ティック後も停止し、60Hzで約3秒、50Hzで約3.6秒です。Spaceを長押ししても繰り返し切り替わりません。

この配列はプリセット画面とDATブラウザ専用で、メイン編集や`K`の鍵盤配列とは異なります。音キーを保持したままEnter/Escで離れると、先に音を止めてキー解放を待ちます。`NO CHIP`は音源なし/応答なしの表示で、編集は継続できます。試聴だけではバンク・現在のスロット・未保存状態・Undo・ファイルを変えません。

## 6. DATブラウザと読込み

`F`または`W`を選び、`O`/Ctrl+Oを押します。DOSの現在のディレクトリからフォルダーと`.DAT`を表示します。上下はファイル、左右はファイル内の音色、Enterはフォルダーへ、Backspaceは上位へ、Escは取消です。DOSの現在ディレクトリやドライブは変えません。別ドライブを使う場合は起動前にDOSで切り替えます。ファイル名はDOS 8.3形式です。

SCCはSCWDヘッダー・長さ・ID・CRC32の検査後に実際の32サンプルを描きます。FMは6文字名・ALG/FB・4オペレータのエンベロープ概略です。**FM図は合成音声の波形や正確なチップシミュレーションではありません。** Spaceや音キーで読込み前に聴けます。

FMは内容があると推定した最初のレコードから表示します。Tabで`NONBLANK`/`ALL`を切替え、NONBLANKの左右は空レコードを飛ばします。パラメータのバイト1〜25または名前26〜31のASCII印字文字を調べ、予約バイト0は無視します。発音可否や使用状態を判定する機能ではありません。意図的な全ゼロ/無音はALLで選べます。フォルダーや不正ファイルは以前の図を残さず説明を表示し、試聴しません。

**DATファイル上のEnterは表示中の1音色ではなくバンク全体を読み込みます。** 自分のバンクを先に保存してください。未保存変更の破棄確認と再検証後、選択中のFM/SCCバンクだけを置換します。取消や読込み/クローズ/形式エラーではバンクとUndoを維持し、成功した読込みではそのバンクのUndoを消去します。

ブラウザ読込み後は記憶した保存名を消去します。次の保存は元のDOSディレクトリで新しい名前を尋ね、閲覧した原本へ直ちに上書きしません。`L`は従来どおり直接ファイル名を入力します。TFI/MUC/VGM取込みは入力ダイアログで行い、このブラウザはDAT専用です。

## 7. YM2608 FM編集とTFI

`F`、`I`で番号を選び、矢印/Tabで項目を選択します。ALGとFBはそれぞれ0〜7です。

| 項目 | 範囲 | 内容 |
| --- | --- | --- |
| AR / DR / SR | 0〜31 | アタック / ディケイ / サステインレート |
| RR / SL | 0〜15 | リリースレート / サステインレベル |
| TL | 0〜127 | トータルレベル。大きいほど減衰 |
| KS | 0〜3 | キースケーリング |
| ML | 0〜15 | 周波数倍率 |
| DT | 0〜7 | Yamahaの生デチューンコード |
| AM | 0〜1 | 振幅変調の有効/無効 |

`/TEXT`の`E`ではオペレータ0でALG/FB、1〜4で各項目を編集します。エンベロープ図は概略です。ALGによってキャリア/モジュレータが変わるため、スピーカー音量は小さく始めてください。

FM DATは32バイト×256レコード＝8,192バイトです。保存順OP1/OP3/OP2/OP4と表示順OP1〜4は異なります。無関係な項目や予約ビットを保持し、無編集の読込み/保存ではバイトを維持します。元のCP932名バイトも保持しますが、非ASCIIは点で表示し、`N`でASCII名に変更します。

TFI取込みは`F` → `I` → 対象番号 → `T` → `BASS.TFI` → `Y`です。標準TFM Makerの42バイト形式で、ALG/FBの後にハードウェアスロット順のML・DT・TL・KS・AR・DR・SR・RR・SL・SSG-EGが4組あります。TFIのDT 0〜6はYamahaコード7,6,5,0,1,2,3へ変換し、AMは0です。追加/不足データや範囲外は拒否し、DT 7以上を推測して補正しません。

現在のFMレコードだけを置換し、名前はファイル名先頭6文字の大文字になります。`U`で戻せます。SSG-EG有効の場合、DATに保存できないため破棄確認を表示します。拒否すると変更しません。許可すると試聴・DAT・MUC・VGMからその設定が失われるので、元TFIを保管してください。

## 8. SCC/SCC+波形編集

`W`、`I`で番号を選び、左右でサンプル0〜31を選択します。符号付き10進数−128〜127を直接入力するか上下で調整します。Shiftは1刻みです。`P`で基本形を用意できます。未定義スロットは編集・プリセット・コピーで定義します。`D`で削除できますが、最後の1波形は削除できません。Undoで復元できます。SCWDに名前欄がないためSCC名の編集はありません。

SCC DATは**SCWD v1**であり、FM VOICE.DATとは別形式です。16バイトヘッダー＋定義レコード34バイト×1〜256個、最大8,720バイトです。ヘッダー/バージョン/予約欄・昇順ID・全長・CRC32を検査します。FM DATと違い、定義済みID一覧も保存します。SCC/SCC+は同じ32個の符号付きサンプルを使えます。SCWDをFMの`VOICE.DAT`として指定しないでください。

## 9. MUC取込みと出力

`R`はファイル全体を解析後、確認して元の番号0〜255へマージします。FMは複数行`@N`、`@N:{...}`、生データ`@%N`を受け付けます。通常定義はFB・ALG、その後OP1〜4それぞれAR・DR・SR・RR・SL・TL・KS・ML・DTの9値です。AMは0になります。生定義は25バイトで、AMと予約ビットも保持し、10進数と`$FF`式16進数を受け付けます。

SCCは符号付き10進数を正確に32個指定します。

```text
@W7 = {
-128,-120,-112,-104,-96,-88,-80,-72,
-64,-56,-48,-40,-32,-24,-16,-8,
0,8,16,24,32,40,48,56,
64,72,80,88,96,104,112,120
}
```

空白・カンマ・セミコロンコメントに対応します。生FMはCRLF/LF/CR、先頭UTF-8 BOM、DOS Ctrl-Z EOFに対応します。SCCは任意のプラス符号と小文字`@w`も可能ですが、`=`と中括弧は必須で、16進数サンプルは受け付けません。

行の最初の有効文字が`@`の定義を取り込みます。外部`#voice`や`@"名前"`プリセットを検索したり、SSG/リズム/ADPCM定義を取り込む機能ではありません。同種の重複ID・不足した定義・範囲外はエラーです。FM/SCC混合ファイルは両方を検査し、選択したバンクだけをマージします。FM `@7`とSCC `@W7`は共存できます。

成功すると最初の取り込み定義を選択して未保存状態にし、そのバンクのUndoを消去します。ファイルにないスロットと他方のバンクは保持します。取消・解析/読込み/クローズエラーでは適用しません。SCCの最初が0番無音なら、試聴前に別番号を選んでください。

`B`は定義済み全スロットを番号順で出力し、FMは`@%N`、SCCは`@W`です。`X`はFM1音色と短い楽譜、または定義済みSCC波形1個だけです。SCC定義のみの出力は完成した楽譜ではなく、対応するパートや音符を別途追加します。FM DATレコード先頭バイトはMUCに相当項目がないため出力しません。FM名はコメントへ最大6バイトを記録し、制御文字を安全に置換します。

## 10. 定義済みスロットとVGM抽出

起動直後はFM1番INIT、SCC0番無音が定義済みです。FM DATに使用ビットはないので、読込むと無音に見えるものも含め256スロットすべてが定義済みになります。`G`用の空きを作るには`I`で置換可能なFM番号を選び、`D` → `Y`で定義フラグを解除します。元の生バイトは消さず、Undoで戻せます。後で新音色を取り込むとバイトを置換します。疎なFM番号一覧を保つにはDATと一緒に`B`のMUCも保存してください。

`G`は非圧縮VGM 1.00〜1.71から選択中の種類を抽出します。現在番号から空きを探し、255の次は0へ戻ります。定義済みスロットを上書きしません。完全一致は統合し、FM25パラメータバイト、SCC32サンプルを比較します。FMの名前/ヘッダーは比較対象外で、新しいFM名は`VGM`です。空き不足では取込み全体を取消し、途中まで適用しません。取消・読込み/クローズエラーではバンクを維持します。成功した一括追加はそのバンクのUndoを消去し、新音色がなければ変更しません。

YM2608は56h/57hと第2チップA6h/A7hを処理し、各チップ6チャンネルを個別に追跡します。完全な25バイトをキーオンと発音中の待機境界で収集します。TLは記録値のまま保持し、正規化しないため音量変更で複数の音色が生じる場合があります。キーオフ後の消音TLは新音色にしません。

SCCはD2hのポート0、SCC+はポート4の波形書込みを扱い、2インスタンス、SCC CH4/5共有、SCC+独立波形を反映します。待機/終了時に完成した32バイトを収集し、実際の発音有無は問いません。部分更新は既知サンプルを再利用し、不明なサンプルをゼロと推測しません。波形書込み禁止を反映しますが、テスト/変形モードの動作自体はSCWDに保存しません。

SSG-EG・ハードウェアLFO・AMS/PMS・FM3特殊モード・一部オペレータのみのキーオンは基本DATでは完全に保持できず、損失確認を表示する場合があります。元の音色名・楽譜の意図・時間軸のパン/音程/音量・波形変更順は復元しません。リズム/SSG楽譜やADPCMサンプルも抽出しません。元VGMを保管してください。

VGZ/gzipはPCで解凍します。拡張子の変更だけでは解凍できません。DACストリーム制御90h〜95h、未定義コマンド、未対応バージョン、切れたコマンド/ブロックは拒否します。他チップの通常コマンドやデータブロックは長さに従って読み飛ばします。VGMのループを反復実行しません。

## 11. 鍵盤試聴とVGM出力

FMの`K`はMAKOTO使用を確認します。SCCは`255`で自動探査、または既知のBIOSスロットIDを指定して確認します。自動はSCC+を優先し、なければSCCを探します。非拡張IDは0〜3、拡張IDは`128 + 基本スロット + 4 × サブスロット`です。MegaFlashROM SCC+ SDが基本スロット1/2でSCCがサブスロット1なら133/134です。任意のスロットを推測して指定しないでください。RAMスロットは拒否します。

```text
キー:  Z  S  X  D  C  V  G  B  H  N  J  M  ,
音:    C C#  D D#  E  F F#  G G#  A A#  B  上のC
```

上下で基準オクターブ2〜6、初期4を変更します。Shiftは1刻みです。最後の上のCを含む全範囲はC2〜C7です。単音で、複数キーは最低音を優先します。FMは解放でキーオフしリリースを聴けます。SCCは即停止します。Space保持中は強制消音、離すと保持中の音を再発音します。Esc/STOP/Ctrl+Cで停止し、音キー解放後に編集へ戻ります。鍵盤演奏だけではバンク・未保存・Undoを変えません。

FMはMAKOTO FM1、SCC/SCC+はCH1・固定音量12です。通常終了では消音し、CPUページスロット/マッパー選択を保持し、BIOSキークリックを復元します。以前の曲・音色・任意のカートリッジバンクは復元しません。未使用状態のカートリッジで使ってください。リセット・電源断・物理故障は通常の終了処理の範囲外です。

`A`は確認後FM1を約440Hzで鳴らし、任意のキーで停止・消音します。`V`はVGM 1.71で、FMは7.9872MHz YM2608、約2秒発音後キーオフ、0.5秒減衰後に消音します。MAKOTO 8MHzとの差は微小です。SCC出力は共通SCC CH1/ポート0で、再生側はK051649/K052539 D2hに対応する必要があります。いずれも1音色の例で、曲全体の出力ではありません。

## 12. 保存・ファイル名・困ったとき

入力ダイアログは現在ディレクトリのDOS 8.3名、例えば`VOICE.DAT`・`BASS.TFI`・`WAVE.VGM`を受け付けます。英数字・`_`・`-`・拡張子の点を使えます。ドライブ・パス・ワイルドカード・デバイス名は拒否します。長い元名はコピーを8.3名にしてください。フォルダー移動はDATブラウザだけです。

成功した`L`/`S`はセッション中、バンク別にDAT名を記憶します。`S`は名前を編集でき、既存ファイルは置換確認します。Ctrl+Sは既知の成功名へ名前/置換質問を繰り返さず保存し、Ctrl+Shift+Sは新名と置換確認を使います。ブラウザ読込みは記憶名を消します。`/TEXT`では空の名前回答で再利用できます。

DAT保存は一時ファイルに書き、閉じて再読込みしバイト比較した後、元をバックアップ名に移して新ファイルを配置します。ディスクバッファ反映を確認後、バックアップを整理し未保存を解除します。失敗時は復元を試みます。`MV$TEMP.$$$`や`MV$BACK.$$$`が既にあれば回復用ファイルを上書きせず停止します。電源断や媒体故障を保証する機能ではありません。回復ファイルの案内が出たら次の保存前にDOSで確認し、大切な原本は別に保管してください。

MUC/VGM出力`B`・`X`・`V`は新規ファイルのみです。別名を使うか、不要な旧出力を自分で整理してください。`File not found`は入力不在、`File exists`は既存出力保護/置換拒否です。他のDOSエラーはコードも表示します。読取り専用なら新名を使います。不正DAT/TFI/MUC/VGMは現在バンクを維持するので、拡張子だけでなく形式を確認してください。

無音ならカートリッジと選択番号を確認します。SCC0番は意図的な無音の場合があり、未定義波形の場合もあります。`NO CHIP`は編集データの消失ではありません。FM DAT読込み後のVGM取込みで空き不足なら`I`、`D` → `Y`を使います。WAV→ADPCMバンク作成、DOS版のJSON/WAV取込み、マウス、外部MIDI/USBベロシティ入力は未対応です。

ライセンスと第三者への謝辞は`NOTICE.TXT`と`LICENSES/`にあります。取り込んだ音色を配布する前に利用権を確認してください。
