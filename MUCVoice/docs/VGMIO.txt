MUCVOICE v0.5beta — VGM에서 FM 음색 / SCC·SCC+ 파형 가져오기
=======================================================

1. 사용 방법

FM 음색: F -> G -> SONG.VGM -> Y
SCC 파형: W -> G -> SONG.VGM -> Y

GUI의 F/W/G는 즉시 실행합니다. 파일명과 Y/N 뒤에는 Enter를 누릅니다.
/TEXT에서는 명령 뒤에도 Enter를 누릅니다. 파일은 현재 디렉토리의 DOS 8.3
이름을 사용합니다. 가져오기만으로 원본 VGM이나 기존 DAT를 수정하지 않습니다.
별도 보조 실행파일은 필요하지 않습니다. 모든 코드는 MUCVOICE.COM에 있습니다.

전체 명령 스트림을 끝까지 검사한 뒤 Y를 눌러 반영합니다. 추가 설정이나
불완전한 음색이 발견되면 손실 허용 질문이 먼저 나옵니다. 이 경우 두 번의
확인이 필요합니다. 허용하지 않으면 N 또는 Esc로 취소하세요.

가져온 뒤 X는 현재 슬롯, B는 정의된 전체 슬롯을 MUC로 출력합니다.
S는 DAT로 저장하며 기존 이름 교체는 Y 확인을 받습니다. V는 시험 VGM을 출력합니다.
FM은 A로 MAKOTO 단음을, K로 건반 연주를 할 수 있습니다. SCC/SCC+도 K와
255 자동 탐색 또는 정확한 슬롯 ID로 건반 연주합니다. KEYBOARD.txt 참고.
V의 CH1 시험 VGM은 공통 SCC 클록/포트 0을 사용하여 양쪽 칩에서 활용합니다.

2. 슬롯 배정과 중복

선택된 뱅크만 변경합니다. 현재 번호부터 빈 슬롯을 찾아 배정하고 255 다음은
0으로 돌아갑니다. 정의된 슬롯은 덮어쓰지 않습니다. FM은 25바이트, SCC는
32바이트를 비교해 기존 뱅크 및 이번 추출 결과의 완전 동일 데이터를 합칩니다.
FM 레코드 헤더/이름은 중복 비교에서 제외합니다. 새 FM 이름은 VGM입니다.
원래 악기 이름·번호는 VGM 레지스터 로그로 알 수 없으므로 복원하지 않습니다.

빈 슬롯이 부족하면 일부만 적용하지 않고 전체 가져오기를 취소합니다.
FM DAT를 불러온 뱅크는 256개 모두 정의된 상태이므로 새 음색용 빈 슬롯이
없습니다. I로 교체할 슬롯을 선택하고 D -> Y로 명시적으로 비운 뒤 G를 누르세요.
U는 비우기를 취소합니다. D는 기존 원시 바이트를 유지하고 사용 플래그만 끕니다.
VGM을 넣으면 비운 레코드가 교체되므로 필요하면 먼저 DAT를 다른 이름으로 보관하세요.
DAT에는 사용 플래그가 저장되지 않습니다. 희소 목록은 B로 MUC에 보관할 수 있습니다.
초기 FM 뱅크는 1번 INIT, SCC는 0번 무음 파형만 정의되어 있습니다.

성공한 일괄 가져오기는 해당 뱅크를 미저장 상태로 표시하고 1슬롯 Undo를
초기화합니다(다른 뱅크 소유 Undo는 유지). 취소·파싱 오류·읽기/닫기 오류·슬롯
부족은 뱅크와 Undo를 보존합니다.
새 음색이 없으면(전부 중복이거나 완전한 정의가 없으면) 아무것도 변경하지 않습니다.

3. 추출 시점과 정확성

YM2608: 0x56/0x57 명령과 두 번째 칩의 0xA6/0xA7을 처리합니다.
각 칩 6채널의 상태를 따로 유지하며, 키온 직후 및 키온 상태의 대기 명령
경계에서 음색을 수집합니다. 음량(TL)을 포함한 25바이트가 모두 기록된 상태만
채택합니다. 채널이 꺼진 뒤의 음소거용 TL 쓰기는 새 음색으로 수집하지 않습니다.
음량 조절 때문에 TL만 다른 여러 음색이 생길 수 있습니다. 원본 작곡 음색의
TL을 추측하거나 자동 정규화하지 않고 기록된 값을 그대로 보존합니다.

SCC/SCC+: 0xD2의 포트 0(SCC), 4(SCC+) 파형 쓰기를 처리합니다.
두 칩 인스턴스를 구분하며 SCC의 채널 4/5 공유, SCC+의 5개 독립 파형을
반영합니다. 대기 명령/종료 시점의 완전한 32바이트 파형을 수집합니다.
실제로 소리가 났는지와 무관하게 완성된 파형 쓰기를 수집합니다. 부분 갱신은
이전에 기록된 나머지 샘플과 합칩니다. 처음부터 알 수 없는 샘플을 0으로
추측해 채우지는 않습니다. 1바이트씩 쓰는 중간 상태를 매번 음색으로 만들지 않습니다.
테스트 레지스터의 파형 쓰기 금지 비트는 반영합니다. 테스트/변형 모드 자체의
동작은 SCWD 파형에 포함되지 않으므로 사용이 발견되면 손실 확인을 요청합니다.

FM 음색 데이터와 음악 재현 전체는 다릅니다. SSG-EG, 하드웨어 LFO,
AMS/PMS, FM3 특수 모드, 일부 오퍼레이터만 키온하는 동작은 현재 기본
VOICE.DAT로 보존할 수 없어 발견 시 경고합니다. 팬·음정·음량 변화의 시간축,
SCC 파형 변경 순서도 음색 뱅크에는 저장하지 않습니다. 원본 VGM을 보관하세요.
이 도구는 리듬/SSG 악보나 ADPCM 샘플을 추출하지 않습니다.

4. 지원 범위와 오류

비압축 VGM 1.00..1.71을 순차적으로 읽습니다. 원본 파일 전체를 RAM에 올리지
않으며 256바이트 입력 버퍼와 32비트 오프셋/데이터 블록 길이를 사용합니다.
루프는 반복 실행하지 않고 파일에 기록된 한 번의 명령 스트림을 검사합니다.
다른 칩의 일반 명령과 데이터 블록은 길이에 맞게 건너뜁니다.

VGZ/gzip 압축 VGM은 PC에서 먼저 압축 해제해야 합니다. 확장자만 VGM으로
바꾸어도 압축은 풀리지 않습니다. DAC 스트림 제어(0x90..0x95), 정의되지 않은
명령, 미지원 버전, 잘린 명령/데이터 블록은 안전하게 거부합니다. 스트림 제어를
조용히 무시해 해당 방식으로 기록된 음색을 누락시키지 않습니다.

화면 캐시를 C200h..CAFFh로 이동했습니다. 초기 SP는 CD00h 이상이어야 하며
작업용 TPA와 스택 여유가 부족하면 시작 시 거부합니다. 추가 매퍼 세그먼트는
예약하지 않습니다.
