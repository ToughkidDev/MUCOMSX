# MUBPLAY 사용설명서

MUCOM88 MUB Player for MSX  
Written by ToughkidCST

`MUBPLAY`는 MUCOM88의 MUB 음악 파일을 MSX에서 감상하기 위해 만든 플레이어입니다. Makoto 카트리지의 YM2608을 사용해서 FM, SSG, 리듬, ADPCM을 재생합니다.

MSX-DOS2 상에서 `MUBPLAY` 뒤에 듣고 싶은 MUB 파일 이름을 붙이면 그만입니다.  처음 사용하시는 분들을 위해 준비할 것부터 차근차근 설명하겠습니다.

이 설명서는 **Makoto(YM2608)용 `mubplay.com`**을 기준으로 작성했습니다.

### MUB로 들으면 어떤 점이 좋은가요?

MUB의 장점 중 하나는 **같은 곡을 담은 압축하지 않은 VGM에 비해 파일 크기가 훨씬 작다는 점**을 들수 있습니다. 저장 공간이 넉넉하지 않은 MSX 환경에서는 PCM을 동반한 음악파일에 대해 꽤 반가운 장점이기도 하구요.

VGM은 연주하면서 음원 칩에 보내는 명령과 그 사이의 시간을 기록합니다. 반면 MUB는 음표, 음색, 효과 등의 음악 데이터를 저장하고, 플레이어가 이를 해석해서 연주합니다. 쉽게 말하면 VGM은 음원 칩을 움직인 기록에 가깝고, MUB는 플레이어가 읽어 연주하는 악보에 가깝습니다. 음 하나를 유지하는 동안에도 계속 바뀌는 효과를 VGM에서는 여러 명령으로 기록할 수 있지만, MUB에서는 효과를 지정하는 짧은 명령으로 표현할 수 있습니다.

사용하는 입장에서는 이런 점이 좋습니다.

- **같은 디스크에 더 많은 곡을 넣을 수 있습니다.** 파일이 작으면 플로피 디스크나 SD 카드에 음악을 모아두기 편합니다.
- **파일 복사와 관리가 가벼워집니다.** 옮겨야 할 데이터가 줄어들기 때문에 여러 곡을 MSX로 가져오거나 백업할 때도 유리합니다.

다만 모든 곡에서 크기 차이가 일정한 것은 아닙니다. PCM이 큰 비중을 차지하는 곡은 MUB도 커지고, 압축된 VGZ와 비교하면 차이가 줄어들 수 있습니다. 파일이 작다고 해서 PCM 전송 시간이 없어지거나 CPU 부하까지 반드시 줄어드는 것도 아닙니다. MUBPLAY는 음악 데이터를 직접 해석해서 연주하므로 기종의 처리 성능도 중요합니다.

작은 곡 파일들을 디스크에 담아두고 MSX에서 하나씩 꺼내 듣는 용도로 사용해 보시면 좋겠습니다.

## 1. 준비할 것

일반적인 음악 재생에는 다음이 필요합니다.

- MSX-DOS2 또는 Nextor를 사용하는 MSX 환경
- 프로그램과 곡 데이터를 올릴 수 있는 여유 메모리와 메모리 매퍼 환경
- Makoto(YM2608) 카트리지
- `MUBPLAY.COM`
- 재생할 `.MUB` 파일

곡에 따라 필요한 메모리와 로딩 시간이 다릅니다. DOS가 실행된다는 이유만으로 모든 크기의 곡을 재생할 수 있는 것은 아닙니다.

MSX2+의 일반 Z80 환경에서도 사용할 수 있으며, turbo R 환경도 고려되고 있습니다. 다만 같은 곡이라도 기종과 처리 여유에 따라 재생 상태에 미세한 차이가 있을 수 있습니다.

실기에서는 Makoto의 소리가 실제로 연결된 스피커나 믹서로 들어오는지도 확인해 주세요. MSX 본체 소리는 들리는데 Makoto 쪽 소리만 들리지 않는다면 오디오 연결과 볼륨을 먼저 확인하는 것이 좋습니다.

### 다른 사운드 카트리지로도 재생할 수 있나요?

이 설명서의 실행 파일은 Makoto용입니다. MSX-MUSIC이나 SCC만으로 대신 재생할 수는 없습니다. Neotron-B(YM2610B)용 버전도 준비되고 있습니다만 이 실행 파일과 구분해서 사용해 주세요. 이 버전에 출력 장치를 선택하는 명령줄 옵션은 없습니다.

## 2. 가장 간단하게 재생하기

처음에는 `MUBPLAY.COM`과 MUB 파일을 같은 디렉토리에 놓고 실행해 보세요.

예를 들어 다음 두 파일이 있다면,

```text
MUBPLAY.COM
SIN002.MUB
```

DOS에서 이렇게 입력하면 됩니다.

```text
MUBPLAY SIN002.MUB
```

`.COM`은 생략해도 됩니다. 곡 파일은 `.MUB`까지 적어 주세요.

이 설명서의 명령 예제에는 DOS 프롬프트를 넣지 않았습니다. 화면에 `D:\>`가 보이더라도 예제의 명령 부분만 입력하시면 됩니다.

### 다른 드라이브에 있는 곡 재생하기

`MUBPLAY.COM`을 실행할 수 있는 위치에서 곡의 경로를 지정할 수도 있습니다.

```text
MUBPLAY D:\SIN002.MUB
```

하위 디렉토리에 있는 곡이라면 이렇게 입력합니다.

```text
MUBPLAY D:\MUSIC\SIN002.MUB
```

파일 이름은 DOS에서 보이는 이름을 사용해 주세요. 처음에는 짧은 8.3 형식의 이름과 간단한 경로를 사용하는 것이 편합니다. 현재 명령줄에서는 공백이 들어간 경로를 따옴표로 묶어 처리하는 기능을 제공하지 않습니다.

한 번 실행할 때 곡은 하나씩 지정합니다. 여러 파일 이름을 나열하거나 `*.MUB`를 지정해서 연속 재생하는 기능은 없습니다.

## 3. 실행하면 어떤 화면이 나오나요?

정상적으로 로딩되면 다음과 같은 안내가 나옵니다. 곡 정보는 파일에 들어 있는 내용에 따라 달라집니다.

```text
MUBPLAY - MUCOM88 MUB Player for MSX
Written by ToughkidCST

Loading MUB file with Makoto (YM2608)
Title : THE SHINOBI
Composer : Yuzo Koshiro
Author : Yuzo Koshiro
Date : 2018/12/12
Comment : sin002
Press any key to stop.

```

로딩이 끝나면 곡 정보를 표시하고, 마지막 안내와 화면 스크롤 처리를 마친 뒤 자동으로 연주를 시작합니다. 시작하려고 키를 한 번 더 누를 필요는 없습니다.

PCM 데이터가 들어 있는 곡은 Makoto로 데이터를 전송하는 시간이 필요할 수 있습니다. 따라서 `Loading MUB file with Makoto (YM2608)`에서 잠시 머물 수 있습니다. 파일 크기와 디스크 속도에 따라 걸리는 시간도 달라집니다.

### 재생을 중단하려면

연주 중에 **ESC나 스페이스 같은 일반 키를 누르면** 중단하고 DOS로 돌아갑니다. ESC만 가능한 것은 아닙니다. Shift나 Ctrl만 누르는 것처럼 문자 입력이 생기지 않는 키 조작은 중단 키로 사용하지 마세요.

별도 옵션이 없으면 기본적으로 한 번 연주하고 종료합니다. 반복 구간이 있는 곡은 그 구간의 반복 경계를 기준으로 종료하며, 반복 구간이 없는 곡은 모든 채널의 연주가 끝나면 종료합니다.

현재 일시정지, 재개, 곡 앞뒤 이동, 채널별 음소거 기능은 없습니다. 처음부터 다시 듣고 싶다면 중단한 다음 같은 명령을 다시 실행해 주세요.

## 4. 반복해서 듣기

반복 횟수는 `/L` 옵션으로 지정합니다. 숫자는 `/L` 바로 뒤에 붙입니다.

| 입력 예 | 동작 |
| --- | --- |
| `MUBPLAY SIN002.MUB` | 기본 한 번 연주 |
| `MUBPLAY SIN002.MUB /L1` | 한 번 연주 |
| `MUBPLAY SIN002.MUB /L2` | 두 번째 연주 구간까지 반복 |
| `MUBPLAY SIN002.MUB /L3` | 세 번째 연주 구간까지 반복 |
| `MUBPLAY SIN002.MUB /L0` | 반복 횟수 제한 없이 연주 |

계속 틀어두고 싶다면 다음처럼 실행하면 됩니다.

```text
MUBPLAY GH002.MUB /L0
```

그만 듣고 싶을 때 키를 누르면 됩니다.

여기서 반복은 **MUB 안에 지정된 음악의 반복 구간**을 따릅니다. 파일을 매번 다시 읽어 인트로부터 새로 재생하는 방식은 아닙니다. 곡이 인트로 뒤의 특정 위치로 돌아가도록 만들어져 있다면 그 위치부터 반복됩니다.

반복 구간이 없는 곡에는 `/L0`을 지정해도 새로운 반복 구간이 생기지 않습니다. 이 경우에는 곡이 끝나면 종료합니다.

현재 숫자는 한 자리인 `0`부터 `9`까지 사용합니다. `/L10`이나 `/L30`처럼 두 자리 수를 지정하는 용도로는 사용할 수 없습니다. `/L 3`처럼 숫자를 띄어 쓰지 말고 `/L3`으로 적어 주세요.

숫자 없이 `/L`만 지정해도 기본적으로 무제한 반복을 선택하지만, 뜻이 분명한 `/L0` 표기를 권합니다.

## 5. 곡 정보 읽기

MUB 파일에 다음 태그가 들어 있으면 로딩 후 표시합니다.

| 화면 항목 | 파일 안의 태그 | 내용 |
| --- | --- | --- |
| `Title :` | `#title` | 곡 제목 |
| `Composer :` | `#composer` | 작곡가 |
| `Author :` | `#author` | 데이터 제작자 또는 편곡자 등 파일에 기록된 작성자 |
| `Date :` | `#date` | 파일에 기록된 제작·변환 날짜 |
| `Comment :` | `#comment` | 설명과 주석 |

정보가 없는 항목은 표시하지 않습니다. 제목만 나오는 곡도 있을 수 있고, 곡 정보 없이 바로 재생 안내가 나올 수도 있습니다. 이것만으로 파일에 문제가 있다고 판단할 필요는 없습니다.

표시 순서는 파일에 기록된 태그 순서를 따릅니다. `#comment`가 여러 번 들어 있으면 여러 줄로 표시될 수 있습니다. 날짜 역시 현재 날짜나 파일 수정 날짜를 자동으로 넣는 것이 아니라, MUB에 저장된 값을 보여줍니다.

### 일본어 제목은 어떻게 표시되나요?

현재 제목 출력은 영문과 반각 가타카나를 기준으로 처리합니다. 반각 가타카나의 실제 모양은 사용 중인 MSX의 문자 환경에도 영향을 받습니다.

예를 들어 `ARG014.MUB`의 제목은 반각 가타카나이므로 일본어 MSX 환경에서는 다음처럼 표시됩니다.

```text
Title : ｶﾗｸｰﾑ ﾉ ﾏﾁ
```

한자나 전각 일본어처럼 현재 출력 방식으로 표시할 수 없는 문자가 제목에 포함되어 있으면, 깨진 글자를 내보내는 대신 제목 전체를 다음과 같이 표시합니다.

```text
Title : [Japanese Title]
```

제목 일부가 영문이어도 표시할 수 없는 문자가 함께 있으면 제목 전체가 대체됩니다.

현재는 한자 ROM이 있는 기종에서도 플레이어가 자동으로 한자 화면으로 전환하지 않습니다. 또한 이 대체 처리는 `Title` 항목에만 적용합니다. 다른 항목에 전각 일본어가 들어 있다면 그 항목은 깨져 보일 수 있습니다.

## 6. VOICE.DAT나 PCM 파일도 같이 넣어야 하나요?

완성된 MUB를 재생할 때는 **별도의 `VOICE.DAT`가 필요하지 않습니다.** 플레이어는 MUB에 포함된 FM 음색 데이터를 사용합니다.

PCM도 MUB 안에 포함된 PCM 블록을 읽습니다. 태그에 `#voice voice.dat` 또는 `#pcm mucompcm.bin`이라는 기록이 보이더라도, 그것이 재생할 때 같은 이름의 외부 파일을 찾아 읽는다는 뜻은 아닙니다.

처음에는 `MUBPLAY.COM`과 재생할 MUB 파일만 준비해서 사용하시면 됩니다.

다만 PCM을 사용하는 곡인데 MUB를 만들 때 필요한 PCM 데이터가 포함되지 않았다면, 플레이어가 외부 PCM 파일을 찾아서 자동으로 보충하지는 않습니다. 이런 경우에는 MUB를 만드는 단계에서 포함 여부를 확인해 주세요.

또한 `.MUC`는 컴파일 전의 음악 소스입니다. `MUBPLAY`에 직접 넣는 파일은 컴파일이 끝난 `.MUB`입니다.

## 8. 옵션 한눈에 보기

기본 형식은 다음과 같습니다.

```text
MUBPLAY 파일명.MUB [/L숫자] [/T] [/V]
```

대괄호는 필요한 옵션만 선택해서 넣으라는 뜻입니다. 실제 명령에 `[`나 `]`를 입력하지는 않습니다.

| 옵션 | 용도 |
| --- | --- |
| `/L0` | 일반 재생에서 무제한 반복 |
| `/L1` ~ `/L9` | 일반 재생에서 반복 횟수 지정 |
| `/T` | 연주를 시작하지 않고 로딩 경로를 점검 |
| `/V` | 재생 데이터를 VGM 파일로 출력 |

옵션 문자는 대소문자를 구분하지 않습니다. `/l2`도 사용할 수 있지만, 이 설명서에서는 읽기 쉽게 대문자로 통일했습니다.

평소 음악을 듣는 데에는 파일 이름과 필요할 때의 `/L` 옵션만 알아두시면 됩니다. 아래 두 기능은 파일 점검이나 비교 작업이 필요할 때 사용해 주세요.

## 9. 로딩만 점검하기: /T  (디버그 용)

```text
MUBPLAY GH002.MUB /T
```

곡을 읽는 과정을 실행한 뒤, 연주를 시작하지 않고 종료합니다. 성공하면 다음 메시지가 나옵니다.

```text
Load test OK.
```

이 모드에서는 메모리 매퍼 정보도 표시합니다. 결과 표시용 파일로 현재 디렉토리에 `LT_OK.TXT` 또는 `LT_NG.TXT`를 생성·갱신하려고 합니다. 이 파일은 사람이 읽는 자세한 보고서가 아니라 점검용 표시 파일입니다. 이전 실행의 파일이 남을 수 있으므로, 파일이 존재한다는 사실만으로 이번 결과를 판단하지 말고 화면 메시지도 확인해 주세요.

한 가지 주의할 점이 있습니다. 현재 `/T`는 **음악 연주를 시작하지 않는 모드**이지, 사운드 카트리지에 전혀 접근하지 않는 모드는 아닙니다. PCM이 들어 있는 MUB는 로딩 중 Makoto로 PCM을 전송하는 경로도 실행합니다. 따라서 Makoto가 없는 환경에서 안전하게 파일 형식만 검사하는 도구로 사용하지는 마세요.

`Load test OK.`는 로딩 경로가 성공했다는 뜻입니다. 곡 전체의 음색이나 모든 재생 명령까지 검증했다는 뜻은 아닙니다.

## 10. VGM 파일로 출력하기: /V

MUB의 재생 데이터를 VGM으로 저장하는 기능. 소리를 녹음해서 WAV나 MP3로 만드는 기능이 아니라, 음원 칩에 보내는 명령과 타이밍을 파일로 기록하는 기능입니다.

```text
MUBPLAY SIN002.MUB /V
```

출력 이름은 입력 MUB의 확장자를 `.VGM`으로 바꾸어 만듭니다. 위 예에서는 `SIN002.VGM`이 됩니다. 입력 경로에 디렉토리가 있으면 출력도 같은 경로를 기준으로 합니다.

**같은 이름의 VGM이 이미 있으면 확인 질문 없이 덮어씁니다.** 이전 파일을 보관하려면 실행 전에 다른 이름으로 옮겨 주세요. 입력 MUB를 VGM으로 바꾸거나 삭제하는 것은 아닙니다.

### /V와 함께 쓰는 /L은 뜻이 다릅니다

현재 버전에서는 `/V`를 지정했을 때 `/L`의 숫자를 **반복 횟수가 아니라 출력할 음악의 시간(초)**으로 사용합니다.

```text
MUBPLAY SIN002.MUB /V /L5
```

이 명령은 약 5초 분량을 출력합니다. 작업 자체가 실제 시계로 5초 안에 끝난다는 뜻은 아닙니다. 파일 쓰기와 PCM 데이터 처리 속도에 따라 작업 시간은 달라집니다.

| 입력 예 | VGM 출력 분량 |
| --- | --- |
| `MUBPLAY SIN002.MUB /V` | 기본 약 30초 |
| `MUBPLAY SIN002.MUB /V /L5` | 약 5초 |
| `MUBPLAY SIN002.MUB /V /L9` | 약 9초 |
| `MUBPLAY SIN002.MUB /V /L0` | 기본 약 30초 |

여기에서도 숫자는 한 자리만 처리합니다. `/L30`으로 30초를 지정하지 마세요. 기본 30초를 원하면 `/V`만 사용하면 됩니다. 음악의 처리 단위에 맞춰 기록하므로 결과 길이는 지정 초수와 조금 다를 수 있습니다.

`/V`는 일반 재생의 키 입력 중단과 같은 동작을 제공하지 않습니다. 지정 분량의 출력을 마칠 때까지 기다려 주세요. `/T`와 `/V`를 함께 지정하면 `/T`가 우선하므로 두 옵션은 따로 사용해 주세요.

이 기능은 비교·점검용 보조 기능입니다. 출력 파일을 확인할 때는 YM2608을 지원하는 VGM 재생 환경을 사용해야 합니다. MSX의 VGMPLAY로 확인한다면 Makoto(YM2608)를 사용하는 환경으로 맞춰 주세요.

## 11. 문제가 생겼을 때

### `MSX-DOS 2 is required.`가 나옵니다

현재 실행 환경이 필요한 DOS2 조건을 충족하지 못한 경우입니다. MSX-DOS2 또는 Nextor로 부팅한 상태인지 확인해 주세요. BASIC 화면에서 바로 사용하는 프로그램은 아닙니다.

### `ERROR: YM2608 (Makoto) not detected.`가 나옵니다

Makoto를 감지하지 못했습니다. 실기에서는 카트리지 연결을, openMSXTK에서는 Makoto extension이 실제로 삽입되어 있는지 확인해 주세요.

MegaFlashROM SCC+ SD만 넣은 상태로는 Makoto가 추가되지 않습니다. 두 extension은 역할이 다릅니다.

### `ERROR: Failed to load MUB file.`가 나옵니다

파일을 읽거나 MUB로 처리하는 데 실패했다는 뜻입니다. 다음 순서로 확인해 보세요.

1. `DIR`에서 파일 이름이 실제로 보이는지 확인합니다.
2. 현재 드라이브와 디렉토리가 맞는지 확인합니다.
3. `.MUC`가 아니라 컴파일된 `.MUB`인지 확인합니다.
4. 다른 MUB 파일도 같은 증상이 나는지 확인합니다.
5. 파일 복사 중 손상되거나 일부만 복사된 것은 아닌지 확인합니다.

파일 확장자만 `.MUB`로 바꾸어서는 재생할 수 없습니다. 또한 이 오류 메시지 하나만으로 원인이 PCM인지, 경로인지, 파일 내용인지 확정할 수는 없습니다.

### 로딩 화면에서 오래 기다립니다

PCM이 큰 곡은 전송 시간이 필요합니다. 우선 다른 작은 곡과 비교해 보세요. 특정 곡에서만 오래 걸리는지, 모든 곡에서 진행이 멈추는지를 구분하면 원인을 찾는 데 도움이 됩니다.

오랫동안 전혀 진행되지 않는다면 단순히 큰 파일이라서 그렇다고 단정하지 말고, 파일 이름과 환경을 함께 알려 주세요.

### `ERROR: Insufficient TPA space.` 또는 메모리 관련 오류가 나옵니다

프로그램이 사용할 수 있는 메모리 여유를 확인해 주세요. 상주 프로그램이나 드라이버 구성에 따라 여유 공간이 달라집니다. 불필요한 상주 프로그램을 줄인 환경과 작은 MUB 파일에서도 비교해 보면 좋습니다.

### 제목이 `[Japanese Title]`로 표시됩니다

정상 동작입니다. 현재 화면 출력으로 처리할 수 없는 문자가 제목에 포함되어 있다는 뜻입니다. 곡 파일이 손상됐다는 뜻은 아니며, 원래 제목과 음악 데이터도 바뀌지 않습니다.

### 소리가 나지 않거나 일부 소리만 다릅니다

먼저 Makoto의 오디오 출력과 볼륨을 확인해 주세요. 특정 곡의 ADPCM만 빠진다면 MUB 안에 필요한 PCM이 포함되었는지도 확인할 필요가 있습니다. `VOICE.DAT`를 옆에 복사하는 방식으로 해결되는 문제는 아닙니다.

같은 파일을 사용해도 원본과 음색·템포가 다르다면 그 차이를 알려 주세요. Z80과 turbo R 환경의 차이, 특정 구간의 처리 부하, 파일의 재생 명령 등도 확인해야 합니다.

### `An exception occurred` 또는 `Address out of bounds`가 나옵니다

정상적인 곡 종료 메시지가 아닙니다. 오류가 난 곡 이름과 표시된 주소·메시지를 가능한 한 그대로 남겨 주세요. 로딩 중인지, 연주를 시작한 직후인지, 특정 구간인지, 종료할 때인지도 중요합니다.

오류 뒤에 소리가 계속 남는다면 우선 외부 볼륨을 줄여 주세요. 이 경우에는 정상적인 종료 처리가 끝나지 않은 것으로 보고 확인할 필요가 있습니다.

## 12. 재생 문제시

곡이 다르게 들리거나 오류가 난다면 다음 내용을 함께 알려주시면 확인하기가 훨씬 수월합니다.

- 사용한 `MUBPLAY.COM`의 배포본 또는 받은 날짜
- MUB 파일 이름과, 가능하다면 재현에 사용한 파일
- MSX 기종과 CPU 실행 모드
- MSX-DOS2·Nextor 및 카트리지 구성
- 실제로 입력한 실행 명령
- 오류 메시지 또는 문제가 들리는 구간
- 비교할 원본 음원과 현재 재생을 담은 녹음·영상

영상은 화면만보다 소리가 함께 들어 있는 것이 좋습니다. 예를 들어 “인트로에서 느려졌다가 빨라진다”, “FM 멜로디가 다르다”, “드럼은 나오는데 PCM이 없다”처럼 들리는 차이를 설명해 주세요.

ESC로 중간에 종료한 영상이라면 그 사실도 적어 주세요. 캡처 길이가 다른 이유와 실제 음악의 속도 차이를 구분하는 데 도움이 됩니다.

## 13. 자주 쓰는 명령 모음

한 곡 듣기:

```text
MUBPLAY SIN002.MUB
```

반복 구간을 세 번째 연주까지 듣기:

```text
MUBPLAY GH002.MUB /L3
```

키를 누를 때까지 반복해서 듣기:

```text
MUBPLAY GH002.MUB /L0
```

D: 드라이브의 곡 듣기:

```text
MUBPLAY D:\BARE75.MUB
```

Makoto가 연결된 환경에서 로딩 점검하기:

```text
MUBPLAY GH002.MUB /T
```

비교용으로 약 5초 분량의 VGM 출력하기:

```text
MUBPLAY GH002.MUB /V /L5
```

처음에는 옵션 없이 한 곡부터 실행해 보세요. 익숙해지면 `/L0`으로 좋아하는 곡을 반복해서 들어보시면 됩니다.

즐겁게 사용해 주세요.
