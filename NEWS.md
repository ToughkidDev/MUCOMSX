# Update News

| Date | Type | News |

| 2026-11-25 | WEB | **[MUCPlayground](https://toughkiddev.github.io/MUCOMSX/MUCPlayground/)** opens **MGS files** (MGSDRV's music data for the MSX's PSG, SCC and MSX-MUSIC): open or drop an `.mgs`, alone or in a playlist, and it is converted to a MUC and played, as an arrangement for the OPNA with the SCC kept. Notes, repeats and tempo carry over as they are; voices, envelopes, vibrato and slides are fitted to the original and are approximations. [Guide](https://toughkiddev.github.io/MUCOMSX/MUCPlayground/Manual/?lang=en#files) |
| 2026-11-22 | RELEASE | **[MucoMSX v1.5-Stable](https://github.com/ToughkidDev/MUCOMSX/releases/tag/v1.5-Stable) released** — the second stable release: the toolchain (MUCEDIT, MUCVIEW, MUCPLAY, MUC2MUB, MUBPLAY) with MUBScope and MUCScope. Since v1.0-Stable: the MUCVIEW viewer, MUBPLAY, MUCPLAY and MUC2MUB on an MSX1, direct start from file managers such as MM, COM + MXR tools, PCM inside a MUB only with `/P`, 8.3 names in `#voice` and `#pcm`, a progress line while a song is prepared, the faster CPU of a Panasonic MSX2+ or a turbo R used while loading and compiling as well, One Chip MSX support, and the sample folders `MUCs` and `MUBs` in the toolchain ZIP. MUCVOICE is replaced by MUCPlayground and VGM output was removed. The release page has the update guide in Korean, English and Japanese; the full list is in the [release notes](shared/docs/RELEASE_NOTES.md). |
| 2026-11-22 | TOOLS | On an **MSX1**, MUBPLAY and MUCPLAY take their tempo from Makoto's own timer (YM2608 Timer B), so songs faster than 60 ticks per second no longer play slowly, and 50 Hz and 60 Hz machines play at the same speed. Both players need the Makoto (YM2608) cartridge and end with `ERROR: YM2608 (Makoto) not detected.` without it; MUC2MUB compiles without it. `/L<n>` in MUBPLAY and MUCPLAY, and ONCE in MUBScope and MUCScope, count a pass when every looping part has come round, so songs whose parts loop with different lengths or from different points no longer end early. MUBPLAY takes the faster CPU of a Panasonic MSX2+ or a turbo R as soon as it starts, so the song read and the PCM upload run fast too. In the packages dated 2026-11-22 or later; the toolchain ZIP now also carries the samples of the scope packages (`MUCs`: 53 MUC songs with their voice and PCM files; `MUBs`: 49 compiled MUB songs) and no longer the starter voice files. [Release notes](shared/docs/RELEASE_NOTES.md) |
| 2026-11-21 | TOOLS | **MUCVIEW** joins the toolchain: a read-only MUC viewer for MSX2 or later. It opens a `.MUC` on the 80-column screen and, from its F1 menu, compiles, plays and exports the song to MUB through MUCPLAY, without an editor and without writing a state file. Manuals: [한국어](MUCView/MUCView.md) · [English](MUCView/MUCViewE.md) · [日本語](MUCView/MUCViewJ.md). It is in the toolchain packages dated 2026-11-21 or later. |
| 2026-11-19 | TOOLS | The four tools, MUBScope and MUCScope run on **MSX-DOS 2** as well as Nextor and start directly from file managers such as MM (Multi Mente): put `.MUB<Tab>MUBPLAY $C` and `.MUC<Tab>MUCPLAY $C` in `MMRET.DAT`. The MUCOMSXE launcher is no longer needed and was removed. The `#pcm` file goes into a MUB only on request (`/P`), `#pcm` and `#voice` take 8.3 file names only (error 21 otherwise), and MUBScope and MUCScope always start in their file browser. [Release notes](shared/docs/RELEASE_NOTES.md) |
| 2026-11-15 | TOOLS | MUBPLAY, MUCPLAY and MUC2MUB also run on an MSX1 (MUCEDIT needs an MSX2), and DOS-prompt messages fit a 40-column screen. [Release notes](shared/docs/RELEASE_NOTES.md) |
