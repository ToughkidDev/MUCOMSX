# MSX-MUSIC・内蔵PSGへの互換出力

2026-10-03実装。YM2608向けMUCの音符・命令を再利用し、YM2413とMSX内蔵PSGで
似た編曲を演奏します。異なるチップ間の波形一致を目的とする機能ではありません。

| パート | 出力 |
| --- | --- |
| MSXA/B/C/H/I/J | YM2413 FM 1～6 |
| MSXG | OPLL BD・SD・CYM・HH・TOM |
| MSXD/E/F | 内蔵PSG 1～3 |
| 接頭辞なし A～K | 従来のMAKOTO/OPNA、変更なし |

`D0`は従来のOPNA SSGです。`MSXD0`が内蔵PSGです。数字省略はページ0。
ページ0～9を使えますが、物理チャンネルを共有するため同時発音数は増えません。
`MSXABC`・`MSXDE`・`MSXA09`も使用可能です。接頭辞は行の選択子全体に適用されます。
OPNAとMSXは別の行に書いてください。`MSXK`とネイティブFM3特殊命令はエラーです。

```text
MSXD @0 v12 t180 o5 l8 cdefgab>c
MSXE @0 v10 o4 l4 c g e g
MSXG v63,31,31,31,31,31,31 @31 l8 c r c r
```

音符、長さ、タイ、反復、マクロ、ソフトウェアLFO、ポルタメントは既存処理を再利用。
PSG周期をクロック変換し、レジスタ7のI/O設定を保存、14/15への音楽書き込みを遮断します。
PSGは音量だけでなく有効なソフトウェアエンベロープも指定してください。

FM音色は2オペレータ向け特徴に縮約し、15個のROMプリセットとのパラメータ距離で
選択します。スペクトル最適化や聴感上の最適一致ではありません。
共有ユーザー音色の上書きは行いません。RIMは省略、左右パンはモノ化し、ミュートは保持。
非対応レジスタ、ハードウェアLFO、SSG-EG、音程範囲超過等は変換警告の対象です。
`y`はOPNAレジスタの意味であり、OPLLレジスタへの直接アクセスではありません。

4ツールの通常操作で使用でき、追加CLI指定は不要です。現在の再生にはMAKOTOと
MSX-MUSICが必要です（PSGだけのMSXパートでも同じ）。対応Panasonicは高速Z80、
turbo RはR800を使用し、終了時に元へ戻します。`/N`は呼び出し時のCPUを維持します。
コンパイル・オフラインVGM出力は自動CPU切替の対象外です。

MSXパート使用曲はMUCOMSX専用`msPb0100`、拡張子は`.MUB`です。
通常のMUB8/muPbの意味は変わりません。他のMUBプレイヤーでの互換性を仮定しないでください。
VGMにはYM2413の0x51、AY PSGの0xA0およびクロック情報をOPNA出力と共に記録します。

入力MUCは65,536バイト、編集文書は正規化後60,000バイト、音楽DATAは122,880バイトです。
ネイティブページのストリーム上限は59,106バイトでヘッダー・タグ・PCMは別です。
最低マッパーは512KiB。ドライバは1バンク、ネイティブページ状態は最大2バンクを追加使用します。
空きメモリはDOS・常駐ソフト・ページ/反復構成に依存します。

格納形式は220ページエントリ、1,986バイトのヘッダ。ネイティブKは終了0バイトのみ、
ループなしで、実行しません。内部DATA F1/F5の接頭部894バイト、音色位置LE32は+886、
全長LE32は+890です。ディスクヘッダのオフセットとは異なります。

比較表はBSD-3-ClauseのymfmにあるDavid Viens・Hubert Lamontagneのプリセットデータです。
NOTICEとYMFM-LICENSEを同梱します。GPL変換コードやNuked-OPLLエミュレータは含みません。
