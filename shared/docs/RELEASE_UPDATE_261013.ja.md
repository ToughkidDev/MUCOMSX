### 実MSX向けSSG拡張

`#SSGExtend On`は接頭辞なしD/E/FをSCC/SCC+の1–3チャンネルで近似します。`@I0..9`・`@W0..255`・`peL,R`に対応し、64個の符号付きサンプルを32個へ変換します。左右パンはモノラル利得への近似です。ノイズ・実チップのエンベロープ経路はMAKOTOを使い、`MSXD/E/F`は内蔵PSGのままです。

SCC+を優先し、通常SCCへフォールバックします。登録RAMマッパーを除外し、基本・拡張スロットと波形RAMを復元可能な方法で検査します。既存バンク内で処理し最低512KiBを維持します。通常SCCで5つの独立SCC+波形を提供する機能ではありません。同一カートリッジのネイティブSCC経路との競合は拒否します。

出力は`msPb0101`で、バイト26の機能値はSSG拡張`2`、ネイティブ混在`3`、予約バイト27–33は0です。MUB8・muPb・msPb0100は引き続き区別し未知の構造を拒否します。VGMは共通SCCクロック/ポートで出力します。[SSG拡張ガイド](SSG_EXTEND.ja.md)を参照してください。他社MUBプレイヤーがMUCOMSX固有のmsPbに対応するとは限りません。

### PCMInvertはPCMデータ反転ではありません

`#PCMInvert On/Off`はKの相対オクターブ`>`/`<`をコンパイル時に逆転します。PCMバイト変換や演奏時の反転処理は追加しません。`#pcm`ファイル名タグとの誤認も修正しました。`#@pcm`によるWAV変換・PCMバンク作成は未対応です。

### リズムミュートとセッション

`#OPNA1RhythmMute`でネイティブMSXターゲットビットを設定し、OPNA音楽ストリームが空になる不具合を修正しました。MUCPLAYセッション/MUCEDIT連携でヘッダーのマスクを復元しない不具合も修正しました。影響を受けた旧MUBは元MUCから再コンパイルしてください。プレイヤー交換だけでは欠落DATAを復元できません。

マスクは音楽命令からのリズムキーオンに適用します。明示的な`y16`は直接レジスタ書込みなので迂回し、キーオフは遮断しません。MDPlayer比較でもこの規則を維持します。リズム自動パン`pm1 p4..p6`は対象ドラムごとに待ち値を出力し、省略時は現在の音長を使います。明示待ち値は1–255です。

### コンパイルとメモリ

空ページ検索の省略・有効行範囲の縮小、マクロ定義索引・コピー/衝突処理、チャンク保存を改善しました。ページエントリ、最初の定義優先、出力バイトを維持します。速度向上率は楽譜に依存します。

## 容量と未対応事項

| 項目 | 上限 |
| --- | --- |
| MUC2MUB / MUCPLAY入力 | 65,536バイト |
| MUCEDIT文書 | 改行正規化後60,000バイト |
| 音楽DATA合計 | 構造・音色表を含む122,880バイト |
| OPNAの1ページストリーム | 59,546バイト |
| ネイティブMSXの1ページ | 59,106バイト |
| 最低マッパーRAM | 512KiB。すべての最大サイズ同時セッション保証ではない |

120KiBはMUBファイル全体の上限ではありません。ヘッダー・タグ・ADPCMは別で、PCMは音楽/音色DATAの後にディスク保存時に追加します。演奏にはPCM/チップ側の制限もあります。増設RAMだけでは音楽DATA上限は増えません。

パート分岐の入れ子、追加OPNA/OPNB/OPM、`@M`・`PCn`・IDEメモ・`#@pcm`は未対応です。YM2413/PSG/SCCの音はYM2608やPC仮想SSGの完全再現ではありません。高負荷曲が通常Z80で毎ティック間に合う保証もありません。自動高速化は演奏中のみで終了時に元CPUモードへ戻ります。`/N`で自動選択を無効にします。

## MUCVOICE — MSXで音色編集・試聴

MUCVOICE v0.5betaは既存4ツールと同じツールチェーンZIPに含まれます。5個のCOMと独自合成の初期音色データを同じ作業フォルダーへコピーし、音色エディタの案内は`MUCVOICE/START.MD`を開いてください。韓国語・英語・日本語の全説明書は別のドキュメントZIPにあります。MSX-DOS2/NextorのScreen 2でYM2608 FM・SCC/SCC+音色とDAT/TFI/MUC/VGMを扱います。PCMバンク作成は行いません。

- オリジナルFM12種・SCC32種、波形タイル、ファイルブラウザのプレビュー。
- Spaceで試聴、`C D E F G A B`で音階、Shiftで上オクターブ。`K`で通常の鍵盤モード。
- 数値位置で直接入力、Tab確定/次、Esc取消。矢印保持は滑らかに加速、Shiftは1刻み。
- FM/SCC別の未保存・Undo、保存名再利用、ファイルエラー区別、移動/終了時の消音。
- FMグラフィックはエンベロープ/パラメータの説明で、実際の合成音声波形ではありません。

同梱プリセットは独自合成データです。取り込む音色の利用条件を確認してください。操作・形式は`QUICK.TXT`・`KEYBOARD.txt`・`MUCIO.txt`・`VGMIO.txt`・`TFI.txt`へ。

## 安全な更新

1. 曲・音色・PCMをバックアップしてMUCEDITを正常終了します。残存セッションは**交換前**のMUCPLAY `/RELEASE`で解放します。
2. 5つのCOMを同じリリースで揃え、別フォルダー/PATHの旧版も確認します。編集したDATを初期プリセットで上書きしないでください。msPb再生には対応するMDPlayerを使ってください。
3. DOS 8.3名・作業フォルダー・`#voice`/`#pcm`を確認し再コンパイルします。`.MD5`は不要です。既存の32文字メタデータ読込みは計算/照合せず、無欠陥の証明ではありません。
4. 保存済みの同じMUC/素材で3経路のMUB全バイトを比較します。未保存編集・改行・タグ差を音楽DATA不具合と分けます。
5. 演奏・反復・終了消音・MUB/VGMを確認します。SHA-256はファイル同一性で、音楽の正解証明ではありません。

ZIP内の`manifest.json`・`SHA256SUMS.txt`と外部`.zip.sha256`で、ZIP自体と展開したファイルを確認してください。出典・ライセンスは`NOTICE.txt` / `LICENSES/`です。
