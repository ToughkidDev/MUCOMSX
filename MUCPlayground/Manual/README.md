# MUCPlayground Manual / 사용 설명서 / ユーザーガイド

**https://toughkiddev.github.io/MUCOMSX/MUCPlayground/Manual/**

- **English:** the user's guide of [MUCPlayground](https://toughkiddev.github.io/MUCOMSX/MUCPlayground/): playing, the editor, the tracker, scope and keys, the channel view, files, samples, playlists, voice / wave / PCM banks and editors, share links, shortcuts and troubleshooting, then the full MML reference (MUCOM88, the mucomDotNET extensions, the MucoMSX chip extensions) and every message explained. Every example opens in MUCPlayground with one click.
- **한국어:** MUCPlayground 사용 설명서입니다. 재생, 편집기, 트래커·스코프·건반, 채널 뷰, 파일, 샘플, 플레이리스트, 음색·파형·PCM 뱅크와 편집기, 공유 링크, 단축키, 문제 해결, 그리고 MML 문법 레퍼런스 전체(MUCOM88, mucomDotNET 확장, MucoMSX 칩 확장)와 메시지 설명을 담았습니다. 모든 예제는 버튼 하나로 MUCPlayground에서 열립니다.
- **日本語:** MUCPlaygroundのユーザーガイドです。再生、エディタ、トラッカー・スコープ・鍵盤、チャンネルビュー、ファイル、サンプル、プレイリスト、音色・波形・PCMバンクとエディタ、共有リンク、ショートカット、トラブルシューティング、そしてMML文法リファレンス全体（MUCOM88、mucomDotNET拡張、MucoMSXチップ拡張）とメッセージの説明を収めています。すべての例はボタン1つでMUCPlaygroundに開けます。

| File | |
|---|---|
| `index.html` | The page (layout, styles) |
| `manual-page.js` | Renders the guide, the MML reference (from `../manual-data.js`, the same data as the app's manual mode) and the messages (from `../diagnostics.js`); contents, search, language, example buttons |
| `guide.ko.js`, `guide.en.js`, `guide.ja.js` | Part 1, the guide, in Korean, English and Japanese |
| `examples.js` | The guide's MML examples (every one compiles) |

The language follows `?lang=ko|en|ja`, else MUCPlayground's own language setting, else the browser's.
