# MUCScope

SCREEN 2 visual player for MSX1 and later: compiles a `.MUC` on the MSX and plays it with channel keyboards, levels, spectrum and SCC waveforms.
MSX에서 `.MUC`를 컴파일해 채널 건반·레벨·스펙트럼·SCC 파형과 함께 연주하는 SCREEN 2 시각화 플레이어입니다.
MSX上で`.MUC`をコンパイルし、チャンネル鍵盤・レベル・スペクトラム・SCC波形とともに演奏するSCREEN 2ビジュアルプレイヤーです。
