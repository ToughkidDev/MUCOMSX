ALGARNA - SCC / OPLL / OPNA rhythm arrangement
2026-10-21

원곡: Yuzo Koshiro. 사용자 제공 ALGARNA_MML의 네 곡을 편곡했습니다.
원본 파일은 수정하지 않았습니다.

ARG006  살룬의 성 / サルーンの城
ARG007  바렌츠의 전투 / バレンツでの戦闘
ARG011  파트론의 산 / パトロンの山
ARG014  카라쿰의 마을 / カラクームの町

구성
- SCCA: 주선율, SCCB: 베이스, SCCC: 대선율.
- 부드러운 리드, 둥근 베이스, 리드 보조, 전투용 밝은 리드의 4개 파형.
- MSXA/B/C: OPLL 3성부 화음. 원곡 진행에 맞춘 전위와 가까운 성부 진행.
  성/산 곡은 바이올린·플루트, 전투/마을 곡은 피아노 계열을 사용합니다.
- 전투/산 곡의 원래 노이즈 타악기만 MSX PSG에 분리했습니다.
- G: OPNA의 내장 BD/SD/CYM/HH/TOM/RIM. 성/마을은 림 중심,
  전투/산은 킥·스네어·하이햇과 구간 끝 탐 필을 보강했습니다.

음악/파일
- 원래의 선율, 템포 t197, 반복 구조와 루프 길이를 유지했습니다.
- 모든 파트에 최초 1틱(약 17ms)만 초기화용 쉼표를 넣었습니다.
  이 쉼표는 루프 밖에 있어 반복 때 추가되지 않습니다.
- ARG011의 4마디 도입부와 ARG014 후반의 9/8 길이도 유지합니다.
- 일반 음표·반복 MML이며 레지스터 스트림이 아닙니다.
- MUC 약 1.8~4.1KB, MUB 약 4.2~5.6KB.
- ARGFM.DAT과 ARGSC.DAT은 MUC와 같은 폴더에 두세요.
- PREVIEW의 WAV는 MDPlayer 엔진 렌더를 한 루프로 잘라 -3dBFS 피크로
  정규화하고 끝 0.4초만 페이드했습니다. MUC의 음량/루프에는 영향이 없습니다.

필요 환경 / 재생
- 최신 msPb0102 대응 MUCOMSX MUCPLAY 또는 MUBPLAY.
- SCC/SCC+ 카트리지, MSX-MUSIC(OPLL), MAKOTO 호환 OPNA.
- 이번 편곡은 SCC 3채널만 사용하므로 독립 5번째 SCC+ 파형은 필요 없습니다.
- MUBPLAY ARG006.MUB /N /L2
- MUCPLAY ARG006.MUC /N /L2
  /N은 일반 Z80, /L2는 두 루프 후 종료하는 확인용 예입니다.
  원래처럼 반복하려면 /L2를 생략합니다.
