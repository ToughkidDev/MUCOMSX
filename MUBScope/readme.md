# MUBScope

SCREEN 2 visual player for MSX1 and later: plays compiled `.MUB` files with channel keyboards, levels, spectrum and SCC waveforms.
컴파일된 `.MUB`를 채널 건반·레벨·스펙트럼·SCC 파형과 함께 연주하는 SCREEN 2 시각화 플레이어입니다.
コンパイル済みの`.MUB`を、チャンネル鍵盤・レベル・スペクトラム・SCC波形とともに演奏するSCREEN 2ビジュアルプレイヤーです。
