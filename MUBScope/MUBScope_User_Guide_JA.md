## 動作環境

- MSX1以降。表示はSCREEN 2、256×192ピクセル、固定16色です。MSX1の16KB VRAMでも表示できます。
- MSX-DOS2またはNextorとRAMマッパーが必要です。512KB以上のRAMマッパーを推奨します。使用可能なメモリーはDOS、常駐プログラム、曲のサイズによって変わります。内蔵マッパーと外付けマッパーがある場合は、起動時に空きメモリーの多い方を選んで使用します。2つを合わせて使うことはなく、構成によってはDOSが使うマッパーだけを使用します。
- プレイヤーとスキン一式を保存できるSD、HDDなどの記憶装置を使用してください。

曲が使用する音源チップを用意してください。拡張子だけでは必要なチップを判断できません。

| 曲の音源 | 必要な機器 | 表示内容 |
| --- | --- | --- |
| MSX PSG | MSX内蔵PSG | PSG 3チャンネル |
| MSX-MUSIC / OPLL | MSX-MUSIC内蔵機種、FM-PACなど | MML再生はFM 6チャンネルと5種類のドラム。生レジスター再生はFM最大9チャンネル |
| OPNA / YM2608 | MAKOTOなどの対応OPNA機器 | FM、SSG、リズム、ADPCM |
| SCC / SCC+ | 対応SCC/SCC+カートリッジまたは拡張機器 | 曲の形式に応じてSCC 3チャンネルまたは最大5チャンネルと波形 |
| 複数のチップ | 曲が指定するすべての機器 | 使用チップに応じたチャンネルと表示ページ |

`msPb`の曲にも指定された実際のチップが必要です。SCCを使用する曲はOPNA機器だけでは再生できません。

対応Panasonic機では高速モード（Z80 5.37MHz）、Turbo-RではR800モードを自動使用します。CPUの自動高速化を使わない場合は、起動時に`/N`を付けてください。

One Chip MSX（OCM）では、`/N`の有無にかかわらず、カートリッジスロットのクロックを3.58MHzに合わせてからCPUを8.06MHzに上げ、Turbo-Rと同じ全画面で動作します。終了時には起動前のCPU速度とスロットクロックに戻します。

CPUによって画面構成が異なります。常に音楽の演奏を画面表示より優先します。

| CPU | 画面 | 画面更新 |
| --- | --- | --- |
| Turbo-R (R800)、OCM 8.06MHz | 全画面：チャンネル表示、スペクトラム、チップページ、メニュー | 毎秒30回 |
| Panasonic高速モード（Z80 5.37MHz） | 全画面 | 毎秒15回 |
| 通常Z80（3.58MHz）または`/N`で起動 | ファイルブラウザーのみの画面 | [通常Z80モード](#通常z80モード)を参照 |

画面は上の固定周期で更新します。音楽の処理が遅れたフレームでは画面を次のフレームに回して音楽を先に処理し、処理が遅れ続ける曲では画面の更新回数が減ります。

## インストールと起動

配布ZIPを展開し、以下のファイルを同じプレイヤーフォルダーに配置します。`SKINS`のサブフォルダー構造を維持してください。

```text
MUBSCOPE.COM
MUBSCPB.BIN
MUBSCPD.BIN
MUBSCPU.BIN
MUBSCOPE.MXR
SKINS/
```

| ファイル | 用途 |
| --- | --- |
| `MUBSCOPE.COM` | プレイヤー実行ファイル |
| `MUBSCPB.BIN` | ファイルブラウザー |
| `MUBSCPD.BIN` | デザインとスキン表示 |
| `MUBSCPU.BIN` | ボタンとUI拡張 |
| `MUBSCOPE.MXR` | ネイティブMSX譜面再生エンジン |

`MUBSCOPE.MXR`は実行ファイルと同じビルドのものを使用してください。ファイルがない場合やバージョンが一致しない場合は起動できません。他のプレイヤーやツールチェーンのMXRファイルで置き換えないでください。

プレイヤーフォルダーから起動するか、プレイヤーフォルダーを`PATH`に入れて曲のある別のフォルダーから起動できます。どこから起動しても、COM/BINモジュール、MXR、スキン、`MUBSCOPE.CFG`はプレイヤーフォルダーから読み書きします。ファイルブラウザーの開始フォルダーと相対パスで指定した曲は起動したフォルダーが基準で、終了すると起動したフォルダーに戻ります。異なる配布版のCOM/BINやスキンを混在させず、更新時は一式を交換します。

```text
MUBSCOPE
```

方向キーで曲を選び、`RETURN`を押すと再生します。

曲を指定して起動することもできます。

```text
MUBSCOPE SONG.MUB
MUBSCOPE SONG.MUB /L1
MUBSCOPE SONG.MUB /L0
MUBSCOPE SONG.MUB /N
```

| オプション | 動作 |
| --- | --- |
| 指定なし、または`/L1` | ONCEモードで起動 |
| `/L0` | LOOPモードで起動 |
| `/N` | CPUの自動高速化を無効にする。再生モードの指定と併用可能 |

コマンドラインで曲を指定すると、SCREEN 2の画面に切り替わる前にDOS画面へ読み込みの進行を表示します。曲データの読み込み中は`Loading MUB`、PCMの読み込み中は`Loading PCM`の後ろに点が増えます。開始時に1つ、以後8KBごとに1つ点が付きます。ブラウザーから曲を開く場合は、画面最上部のタイトル行に段階名（`READ`：曲データ、`PCM`：ADPCM転送）と進行バーを表示します。バーは段階ごとに最初から伸び直し、残り時間ではなく読み込んだ量を表します。情報・ミキサー・全体リスト画面を開いている間は表示しません。

直前の曲と同じPCMを使う曲は、OPNAに残っているPCMが同じかを確認して転送を省くため、早く始まります。

初期再生モードは**ONCE**です。MUB8と対応するmuPb/msPb形式のMUBを再生します。MUCソースにはMUCScopeを使用してください。音色はMUB内のデータを使用します。PCMは次の順序で決めます。

1. MUBにPCMが入っていればそれを使用します。
2. 入っていなければ、MUBの`#pcm`タグに書かれたファイルをMUBと同じフォルダーで探してOPNAに転送します。MSX-DOSはファイル名の先頭8文字しか見ないため、タグが`schemepcm.bin`ならファイルは`SCHEMEPC.BIN`にしてください。
3. そのファイルもなければ、その曲の間はADPCMパートだけが鳴らず、他のパートは通常どおり演奏します。前の曲のPCMが代わりに鳴ることはありません。

MSX2以降でMAKOTOを接続した構成では、演奏を始める前に曲の冒頭を先に計算し、メモリーセグメント1つ（16KB）に溜めます。そのため曲を開いてから音が出るまで少し時間がかかることがあり、溜めている間にキーを押すとすぐに演奏を始めます。演奏中も先に計算し続けるため、画面処理が一時的に集中しても音は遅れません。先の計算が演奏に追いつかなくなった場合、その曲は直接出力方式に切り替えて演奏を続けます。一部のネイティブMSX楽譜の曲は最初から直接出力方式で演奏します。

## キーボード操作

画面下部のアイコンには、次の順序でキー名が表示されます。

```text
F10  1  2  3  4  5  6  7  8  F  I  V  RETURN
```

| キー | 操作 |
| --- | --- |
| `F10` | スキン選択画面を開く。実機では`Shift+F5`または`Ctrl+L`。 |
| `1` | 停止。再生データを保持して再生の再開に備える。 |
| `2` | 現在のブラウザーフォルダーの前の曲。 |
| `3` | 0.5倍速 → 0.25倍速 → 通常速度を切り替える。 |
| `4` | 再生中は一時停止、一時停止中は再開、停止中は現在の曲を最初から再生。 |
| `5` | 通常Z80は2倍速 → 通常。Panasonic高速モード/R800は2倍速 → 4倍速 → 通常。 |
| `6` | 現在のフォルダーの次の曲。RANDOMではランダムに選択。 |
| `7` | ONCE → LOOP → RANDOMを切り替える。 |
| `8` | フェードアウト後に停止。 |
| `F` | 全画面ファイル一覧を開閉する。 |
| `I` | タイトル、現在のパス、使用チップ、操作説明を表示。 |
| `V` | マスター/音源グループ別の音量ミキサーを開く。 |
| `RETURN` | 選択した曲を再生、または選択フォルダーへ移動。 |
| `Tab` | 再生画面のチャンネル表示/スペクトラムを切り替える。 |
| `Shift+Tab`（`C`も可） | 曲で使用する音源の表示ページを切り替える。 |
| `Ctrl+Tab` | 6種類のボタンスタイルを切り替える。 |
| `Space` | 再生画面で停止。 |
| `Esc` | 一覧/情報/ミキサーから再生画面へ戻る。再生画面では終了。 |

通常Z80では`F10`、`F`、`V`、`Tab`、`Shift+Tab`、`Ctrl+Tab`は使えません。詳しくは[通常Z80モード](#通常z80モード)を参照してください。

再生中はMSXのキークリック音を切ります。キーの音が音楽に混ざらないようにするためで、プログラムを終了すると元のキークリック設定に戻ります。

`F`、`I`、`V`、`C`、`D`は大文字・小文字の両方が使えます。キーを押し続けても自動反復せず、1回だけ入力されます。一覧の上下移動やページ移動も、1回押すごとに1行（1ページ）ずつ動きます。スキン選択画面では方向キーが反復します。

**openMSXのF10設定:** 付属の`openmsx-designs.tcl`を起動時に読み込むと、PCキーボードの`F10`、`Shift+F10`、`Ctrl+Tab`、`Shift+Tab`が接続されます。アルバム用`.command`/TCLを使用している場合は、そのランチャーで起動してください。F10が使えない場合はMSXへ`Shift+F5`または`Ctrl+L`を送ります。

チップページにかかわらず、下部の共通欄に OPNA リズム（BD・SD・CY・HH・TM・RM）、OPLL リズム（BD・SD・TM・CY・HH）、ADPCM-B レベルを表示します。両チップのリズム表示は独立しており、未使用チャンネルは消灯します。SCC 波形はその上に表示されます。

SCC波形は各チャンネル横32ピクセルで表示し、音色の32サンプルを横1ピクセルずつ配置して、縦は6行に縮めて描きます。チャンネル名とゲインは上の行に表示します。隣の波形との間と、下のリズム表示の行との間に余白を設けています。これは音色メモリーの波形であり、出力音量を反映したオーディオ波形ではありません。`GFF`はゲイン値FF（16進数）を示します。

## 通常Z80モード

通常Z80（3.58MHz）で実行した場合、または`/N`で自動高速化を無効にした場合は、CPUをできるだけ音楽の演奏に使うため、画面をファイルブラウザーだけにします。

- 画面最上段に曲名と状態（PLAY・PAUSE・STOP、速度、再生モード）を表示し、残りの領域すべてをファイルブラウザーに使います。
- チャンネル表示、スペクトラム、チップページ、スキン選択、全画面ファイル一覧、音量ミキサーは使えません。下のボタンのうち`F10`、`F`、`V`のアイコンは暗く表示します。
- 再生中は、チャンネル表示のためのチップ状態の記録や描画を行いません。音は高速CPUの場合と同じです。

| キー | 動作 |
| --- | --- |
| `↑` `↓` `←` `→`、`RETURN`、`Backspace`、`+` `=` `-`、`D` | ファイルブラウザーの操作 |
| `1`〜`8` | 停止、前の曲、減速、再生/一時停止、加速、次の曲、再生モード、フェードアウト |
| `Space` | 停止 |
| `I` | 曲情報を開く。`Esc`、`Tab`、`I`でブラウザーに戻ります |
| `Esc` | ブラウザーで押すとプログラムを終了 |
| `F10`、`F`、`V`、`Tab`、`Shift+Tab`（`C`）、`Ctrl+Tab` | 使えません |

曲情報画面のヘルプには`F10`、`F`、`Tab`の説明がそのまま表示されますが、通常Z80ではこれらのキーは動作しません。音量ミキサーを使えないため、音量は常に初期値（最大）です。

音楽の処理だけでCPUをほぼ使い切る曲では、曲情報画面が開くまで時間がかかることがあります。それでも一部の曲は通常Z80の処理能力を超え、本来より遅く演奏されることがあります。そのような曲はPanasonic高速モードやTurbo-Rで再生してください。

通常Z80では、フォルダーやドライブを移動するとき、一覧を読み込んで描画する間だけ音楽を一時停止し、終わると止まった位置から再生を続けます。曲の多いフォルダーほど長く止まります（60曲のフォルダーで約6秒）。自分で一時停止していた場合は一時停止のままです。

## ファイルブラウザー

選択中の項目と再生中の曲は別です。カーソル移動だけでは再生曲は変わりません。`RETURN`で選択した曲を開きます。

| キー | 一覧での操作 |
| --- | --- |
| `↑` / `↓` | 選択を移動 |
| `RETURN` / `→` | ファイルを開く、またはフォルダーに入る |
| `Backspace` / `←` | 親フォルダーへ戻る |
| `+`または`=` | 次のページ |
| `-` | 前のページ |
| `D` | 次の使用可能なドライブ |
| `F` | 全画面ファイル一覧を開閉 |

MSX-DOSの8.3形式のファイル名を使用します。一覧にはファイル名、タイトル、サイズを表示します。タイトルを読めない場合はファイル名で確認してください。長いタイトルは画面幅に合わせて省略されることがあります。ファイル名とタイトルの`~`と`$`も表示します。フォントにない文字（日本語など）は`?`と表示します。

サイズは**KB単位**で、1KBは1,024バイトです。端数は切り上げるため、1,025バイトは`2KB`と表示します。フォルダーは`DIR`です。

PCMを含むMUBは`13KB+189KB`のように曲データとPCMのサイズを分けて表示します。それぞれ個別に切り上げた値です。パスの行の右端にある`MUB+PCM`は、このサイズ列の見出しです。

MacやWindowsで長い名前のファイルをSDにコピーすると、`KONAMI~1`や`09DUST~1.MUB`のような短い名前が作られます。MUBScopeはこのような名前のフォルダーや曲もそのまま開いて再生します。

フォルダーを探索している間も現在の曲は再生を続けます。通常Z80ではフォルダーを移動する間だけ音楽を一時停止します（[通常Z80モード](#通常z80モード)を参照）。新しい曲を開くと、以前の曲を停止してから新しい曲を準備します。前後の曲や自動曲送りは、現在のブラウザーフォルダー内の再生可能なファイルが対象です。

一覧は親フォルダー項目を含めて最大192項目を保持します。大きなフォルダーで曲が表示されない場合は、アルバム別のサブフォルダーに分けてください。

全画面一覧、曲情報、ミキサーでは`Esc`または`Tab`で再生画面に戻ります。情報/ミキサーの方向キーは、その画面の操作に使われます。

## 再生モードと速度

### ONCE・LOOP・RANDOM

| モード | 動作 |
| --- | --- |
| ONCE | ループがある曲は初回演奏の後に指定されたループ区間をもう1回演奏し、次の曲へ進む。ループがない曲は1回演奏する。フォルダーの最後の曲の後は停止。 |
| LOOP | 現在の曲を繰り返す。 |
| RANDOM | 現在のフォルダーから別の曲をランダムに選ぶ。 |

ONCEの追加演奏はイントロの先頭ではなく、曲のループ位置から始まります。読み込み済みのデータを使います。`7`でモード表示と下部のモードアイコンが同時に変わります。LOOPも準備済みの曲データを使用します。

### 一時停止・停止・フェード

`4`で現在の位置を保持して一時停止します。もう一度`4`を押すと、**通常の1倍速**で再開します。再生中の4番アイコンは一時停止、停止/一時停止中は再生の形になります。

曲の終了と一時停止の入力が重なった場合も、自動曲送り・ランダム選択・ループ再開は待機します。`4`で再開すると保留中の終了処理を行い、停止すると取り消します。 フェードアウト中に一時停止するとフェードの進行も止まり、再開すると残りのフェードを続けます。

`1`で停止した後、`4`で現在の曲を最初から再生します。同じ現在のファイルを`RETURN`で開く場合も保持したデータを使います。別の曲を開くか終了すると、以前の曲のデータは解放されます。

`8`でフェードアウトを開始します。完了後は停止し、自動的に次の曲を開く動作とは異なります。

### 再生速度

- `3`: 通常 → 0.5倍速 → 0.25倍速 → 通常。
- 通常Z80の`5`: 通常 → 2倍速 → 通常。
- Panasonic高速モード/R800の`5`: 通常 → 2倍速 → 4倍速 → 通常。

加速中に`3`を押すと0.5倍速、減速中に`5`を押すと2倍速になります。実際の処理速度は機種、曲、画面処理の負荷によって変わります。

## 表示とスキン

### チャンネル表示とスペクトラム

`Tab`で表示を切り替えます。

- **チャンネル表示:** 使用チップに応じたチャンネル名、鍵盤上の音、レベル、音名、対応するパン情報を表示します。SCCでは波形とゲインも表示します。
- **スペクトラム:** 周波数ごとの活動と各チャンネルのレベルを表示します。配置と色はスキンで変わります。

タイトルの下には、曲で使用するチップをすべて`OPNA`、`SCC+`、`OPLL`、`PSG`の順に表示します。たとえば`OPNA/SCC+`、`SCC+/PSG`、`OPNA/OPLL`のようになります。曲データからはSCCとSCC+を区別できないため、SCCは常に`SCC+`と表示します。チップページを切り替えてもこの表示は変わりません。

音名はMUCOMの表記どおり`+`を使います。たとえば`C+4`はC#4です。ADP1行の音名欄には、現在のADPCMサンプル番号を`P03`のように10進数で表示します。MMLの`@3`に当たります。

MSX PSGとOPLLの行も演奏中の音、鍵盤、レベルを表示します。OPLLはキーオフ後も同じ音と音量が続く間は半分のレベルで残り、リリースを表します。休んでいるチャンネルはレベル0です。

スペクトラムとレベルは演奏データとチップ状態から算出した表示です。実際の音声を解析するFFTや録音レベルメーターではありません。パン情報のないモノ音源ではパン表示が動かないことがあります。RHY行の表示灯はリズムの打撃に合わせて点滅します。OPNAは6種類、OPLLは5種類です。一時停止・停止中は消灯します。ネイティブraw PSGではトーンとノイズの両方が無効なチャンネルのレベルは0となり、ノイズのみの発音に鍵盤の音程は表示しません。OPLLのリズムモードを解除すると、7～9チャンネルは直ちにメロディー表示へ戻ります。

チャンネル表示・スペクトラム表示で`Shift+Tab`または`C`を押すと、曲で使用するOPNA、OPLL、SCC(+)+PSGのページを切り替えます。SCCとPSGを併用する曲はSCC 5チャンネルとPSG 3チャンネルを同じページに表示し、SCCのみの曲は5チャンネル表示です。情報・ミキサー・全画面ブラウザーではフォーカスを維持します。切り替え中は一時停止し、完了後に直前の再生・一時停止状態へ戻ります。`msPb`形式だけを理由にOPLL表示になることはありません。

新しい曲を読み込むと、使用パートの構成から主なチップページを自動選択します。通常のパートは使用チャンネル数で比較し、リズム・ADPCM-B・テンポ設定だけのパートは除外します。複数チャンネルをまとめたrawストリームでは、検出したチップのチャンネル数から推定します。SCC(+)+PSGは一つのページとして数え、同点の場合は優先します。同じ曲の停止・再開やメニューからの復帰では、手動で選んだページを維持します。別の曲を読み込むと再選択し、情報・ミキサーパネルが開いている場合は閉じた後に表示します。

**画面切り替え中は短時間、一時停止して消音します。** Panasonic高速モードでは`Tab`の切り替えに約0.3秒、チップページの切り替えに約1秒かかります。 完了後に以前の再生/一時停止、速度、フェード状態を復元します。ADPCMも位置を保持するよう処理します。手動で一時停止してから表示を変えても、自動再開はしません。

### スキンの選択

1. `F10`、または実機の`Shift+F5`/`Ctrl+L`で選択画面を開きます。
2. 方向キーで4つのプレビューから選びます。
3. `[`/`]`で前後のページに移動します。
4. 選択画面の`Tab`でチャンネル/スペクトラムのカテゴリーを切り替えます。
5. `Space`で実寸プレビューを表示し、キーを押して選択画面に戻ります。
6. `RETURN`で適用・保存、`Esc`で適用せずに戻ります。

チャンネル用は**C01～C40**、スペクトラム用は**V01～V40**です。各カテゴリーは1画面4つ、10ページです。2種類の表示のスキンは別々に選べます。

### プレイヤーボタンのスタイル

`Ctrl+Tab`で次の順序に切り替わります。

```text
SOLID → OUTLINE → BADGE → KEYCAP → CUTOUT → BRACKET → SOLID
```

スタイルを変えてもキー配置と機能は同じです。再生、一時停止、モード、フェード、速度の状態に応じてアイコンや強調色が変わります。

## 音量と曲情報

`V`でミキサーを開きます。`↑`/`↓`でグループを選び、`←`/`→`または`+`/`-`で調整します。**0はミュート、15は最大音量**です。

| グループ | 調整対象 |
| --- | --- |
| MASTER | 全体の音量 |
| OPNA FM | OPNA FMチャンネル |
| OPNA SSG | OPNA SSGチャンネル |
| ADPCM | OPNA ADPCM |
| OPNA RHYTHM | OPNAリズム |
| MSX PSG | MSX PSGチャンネル |
| MSX SCC | SCC/SCC+およびSCCで再生するSSG拡張 |
| MSX-MUSIC | OPLL FMチャンネルとドラム |

SCCの音量は**MSX SCC**で調整します。OPNA SSG、MSX PSGとは独立しています。未使用グループの操作では曲の音量は変わりません。

`I`でタイトル、パス、使用チップ、操作説明を表示します。情報/ミキサーは`Esc`、`Tab`または同じメニューキーで閉じます。

## 設定の保存

チャンネル/スペクトラムのスキンとボタンスタイルは`MUBSCOPE.CFG`に保存され、次回起動時に復元されます。以前の名前の有効な設定があれば、初回に復元して正式名で保存します。保存にはプレイヤーフォルダーへの書き込み権限が必要です。別のフォルダーから起動しても、設定はプレイヤーフォルダーに保存します。

音量、速度、再生モードは現在の実行に適用されます。次回起動はONCEが初期値です。LOOPで起動するには`/L0`を付けます。

初期デザインに戻す場合は、終了後に`MUBSCOPE.CFG`を別名に移動して再起動します。

## トラブルシューティング

### 起動直後にモジュールやスキンのエラーが出る

必須COM/BIN、`MUBSCPU.BIN`、`SKINS`一式が同じプレイヤーフォルダーにあるか確認し、異なる版のモジュールを混在させないでください。別のフォルダーから起動した場合は、プレイヤーフォルダーが`PATH`に入っているか確認します。`SKINS/0`～`SKINS/8`、`SKINS/TB0.BIN`～`SKINS/TB5.BIN`も必要です。

### メモリー不足

RAMマッパーを使えるMSX-DOS2/Nextorか確認します。不要な常駐プログラムを終了し、小さな曲で確認してください。大きな曲には多くの空きRAMが必要です。512KB以上のRAMマッパーを推奨します。

### 一覧に曲がない

ドライブ、フォルダー、`.MUB`拡張子を確認します。MUCはMUBScopeの再生対象ではありません。項目が多いフォルダーはサブフォルダーに分けてください。

### 画面は動くが音が出ない

`4`で再生状態を確認し、MASTERと使用音源の音量が0でないか確認します。必要なOPNA、MSX-MUSIC、SCC/SCC+機器の接続も確認してください。SCC/SCC+の使用方式が競合する曲は読み込めません。

### F10やCtrl+Tabが使えない

通常Z80（または`/N`で起動）では`F10`、`F`、`V`、`Tab`、`Ctrl+Tab`を使えません。[通常Z80モード](#通常z80モード)を参照してください。実機では`Shift+F5`または`Ctrl+L`でスキンを選びます。openMSXでは起動時に`openmsx-designs.tcl`を読み込むか、キー設定を含むアルバムランチャーを使用します。ホストOSが組み合わせキーを先に使っていないか確認してください。

### 表示切り替えで音が一瞬止まる

`Tab`とチップページ切り替えは移行中に一時停止し、以前の状態を復元します。再開しない場合は手動一時停止を確認し、`4`を押してください。切り替え時間は機種、記憶装置、スキンによって変わります。

### スキンやボタン設定が保存されない

プレイヤーフォルダーと`MUBSCOPE.CFG`への書き込みを確認します。プレビューだけでは保存されないので、`RETURN`で適用してください。

### 再生や画面の更新が遅くなる

通常の Z80 では画面をファイルブラウザーだけにして演奏に CPU をできるだけ回しますが、一部の曲の命令処理量が CPU の能力を超え、再生速度が低下します。対応する Panasonic 機の高速モードや Turbo-R の R800 自動加速を利用してください。`/N` 付きで起動している場合は、オプションなしで起動し直してください。画面が動いていても、本来のテンポで再生できているとは限りません。

高速な CPU でも、大きな曲は開始直後に少し遅れ、すぐに通常の速度に戻ることがあります。

### FM 音色の多い MUB を開けない

現在の再生ローダーが扱える FM 音色テーブルは最大 32 音色です。muPb/msPb 形式で上限を超えるファイルは、ロードエラーとして扱います。対応する拡張子でも、すべてのファイルサイズや音色数に対応するわけではありません。

## SCC専用5チャンネルの楽譜

`msPb 0102`形式のSCC専用5パート（SCCA–SCCE）に対応しています。PSG・OPLL・OPNAとの混在曲も、それぞれのチップページで確認できます。通常のSCCは第4・第5チャンネルの波形を共有し、SCC+は5つの独立した波形を使用します。

SCC音色の波形はコンパイル済みMUBに含まれます。MUBの再生時に元のMUCのSCCVOICE.DATは不要です。

## ネイティブMSX譜面

PN1–PN6形式のMSX譜面とOPNAを併用したMUBに対応します。使用されるPSG・SCC/SCC+・OPLLの経路に合わせてチャンネルページを表示します。チップページを切り替えても、OPNA・OPLLのリズムとADPCM-Bの共通モニターは維持されます。

ネイティブMSX楽譜はチャンネルごとに繰り返しを数えます。動作中のすべてのチャンネルが1回以上繰り返したときを1周とみなすため、繰り返し区間が最も長いチャンネルが曲の1周になります。繰り返さずに演奏中のチャンネルがあれば、そのチャンネルが終わるまで待ちます。ONCEでは最初の演奏後にこの1周をもう一度演奏します。楽譜中の有限回の繰り返しやフレーズ呼び出しは、曲全体のループ回数には数えません。停止後に現在の曲を再生し直すと、ループ回数も最初に戻ります。

## 圧縮MSX構文への対応

`|` 区切り、最大2段の `[ ... ]n` 繰り返し、`L` ループを使う圧縮MSX楽譜からコンパイルしたMUBを再生します。 OPLLの音色・ドラム設定、休符、SCC波形モーフィングに対応します。ONCEでは、`L` のループ区間をもう一度再生してから次の曲へ進みます。
